# Rin Desktop 0.3 · 本地语音工作台

先自行安装 Windows 原生 Codex CLI，并确认终端中的 `codex --version` 与 `codex login` 正常。应用不捆绑 CLI，沿用当前用户的登录；自定义位置可设置 `VIBE_CODEX_BINARY` 指向 `codex.exe`。随后使用 Release 安装器，开始菜单打开「Rin Desktop」。便携目录可整体移动后运行 **VibeVoice.exe**，不要只复制 exe。CLI 已装但尚未登录时可通过气泡发起官方浏览器登录。Codex 桌面可关闭，推理仍需联网；听写与播报在本机运行。

数据默认保存在 `%LOCALAPPDATA%\VibeVoice`，名称为兼容旧版本保留，安装器不包含或复制登录凭据。从早期便携版升级时，在工作台「壁纸与设置」点击「使用已有数据目录」，选择旧的 `workspaces.json` 所在目录，重启后沿用原项目、会话、草稿与设置。安装升级和卸载不删除用户数据。

基础包不包含语音模型。进入工作台「壁纸与设置 → 本地语音模型」，点击「下载并载入模型」后直接从 Hugging Face 下载，显示百分比和进度条，支持取消和继续下载。准备后点击「载入模型」复用本机文件，「释放模型」仅释放内存。模型保存在数据目录的 `voice-resources`，成功准备后删除下载缓存。Qwen 首次使用还从上游准备独立 Python 与依赖；Microsoft Visual C++ 14.44 运行库缺少时从微软下载，可能需要一次管理员确认。安装和普通启动不自动下载模型。

## 对话与项目

- **Ctrl+Alt+空格**：呼出 / 收起气泡。点击气泡中的项目名称，或 **Ctrl+Alt+P** 打开工作台。
- 左侧 `+` 添加现有项目文件夹，右侧新建对话，或选择已有对话查看历史并继续。重命名只改会话标题；移除入口不删除文件。
- 气泡只保留当前轮回复，工作台可查看完整历史并加载更早消息。输入草稿按项目与对话分别保存。
- 任务执行期间可查看历史，切换需等待或停止当前任务。请避免在其他 Codex 客户端同时继续同一条对话。
- 模型与推理强度可在「壁纸与设置」中调整，不修改全局 CLI 配置。授权与问题仍在气泡中确认。
- 拖动气泡顶部移动，双击顶部空白处回到人物旁；「展开阅读」临时全屏。

## 壁纸人物

工作台「壁纸与设置 → 壁纸人物」可在默认女生和黑衫男生之间选择。黑衫男生为黑色短发、金丝眼镜、黑衬衫与西裤的东亚男青年；两套人物均支持雨夜场景、打字、呼吸和抬头互动。新人物载入成功后自动保存，重启恢复；载入失败时保留原人物和声线，可点击「重试加载」。

新人物载入成功时会停止当前播报，并设置两种引擎的默认声线：女生为 Serena / Kokoro zf_001，男生为 Dylan / Kokoro zm_009。可以继续手动选择声线；不会自动下载、载入模型或开启自动播报。

## 语音

- 回复完整后默认响一次轻柔的双音提示，气泡收起时也能播放，无需加载播报模型。在工作台「壁纸与设置 → 回复提醒」可立即关闭或试听；不会对生成中的文字、恢复的历史、失败或停止的任务播放完成提示。
- **Ctrl+Alt+V** 或「听写」开始录音，再按一次结束。单次最长 60 秒；Esc 取消。识别文字只填入输入框；等待识别完成后，**Ctrl+Alt+Enter** 全局发送当前草稿，或在输入框内按 Enter。识别中、当前任务未结束、草稿为空时不会排队或提交，也不会用发送键批准权限请求。
- 在「壁纸与设置」选择电脑麦克风。Windows 需允许桌面应用访问麦克风。
- **默认不加载播报模型、不自动发声。** 气泡的「语音设置」或工作台「壁纸与设置」可开启「常驻加载播报模型」。开关立即生效并记住下次启动的选择；加载成功显示「已常驻 · 可朗读」。再次关闭会停止声音和合成，退出语音进程，释放模型内存与显存。
- 加载后点击「朗读此条」或按 **Ctrl+Alt+R**，完整准备当前回复的语音后再连续播放，气泡收起也可操作。准备过程中按一次朗读键，会在完成后播放；已明确开启常驻、模型仍在加载时，也可按一次排队等待。重复按键不会重启合成或叠加声音。模型未开启时打开语音设置，不自动加载。**Ctrl+Alt+S** 或「停止播报」取消声音、生成和待播放请求；切换对话、发送新任务、开始听写也会取消旧回复，保留已加载模型。
- 「回复完成后提前准备语音」独立可选，默认关闭。开启后在收到新回复时后台合成，占用算力，但不会自动发声；自动播报仍由另一个开关控制，默认关闭。完成提示音不等待语音生成。关闭提前准备会取消未要求播放的后台任务，不影响已手动要求的朗读。
- Qwen3-TTS 1.7B 为试用引擎，可选择 Serena / Vivian 女声及 Dylan / Uncle Fu 男声。Kokoro 轻量引擎也提供中文男女声。代码块与网页地址用简短提示替代；180 字以内尽量整条合成，较长回复按自然边界分段，全部成功后合并成一个音轨播放，保留自然停顿，不在播放中等待模型。首声仍可能等待较久，界面显示已准备段数，可随时取消。单段失败或超出长度/容量限制时不会播放残缺回复。
- 已完成语音只在内存中缓存，最近最多 3 条、总计最多 32 MiB（单条也受此上限约束）。再次朗读复用相同音频。缓存按项目、会话、回复、正文和声音配置区分；修改声线、卸载模型或退出会清理缓存。不写入磁盘、不下载新模型；超长回复可改为请求较短的回复再朗读。
- Qwen 模型直接从 Hugging Face 下载，Python 和依赖从 Astral、PyPI / PyTorch 上游准备，不依赖开发环境，也不由本项目重新分发。使用它需要兼容 CUDA 12.8 的 NVIDIA 驱动，建议 8 GB 显存。没有合适显卡时，关闭常驻或使用 Kokoro；文字对话与 CPU 听写仍可用。不自动切换为 Qwen CPU 推理。「选择资源目录」可复用已有完整资源，支持 `python/python.exe` 与旧 `.venv`。
- 本机实测 Qwen 常驻后工作集约 2 GiB，显存约 4.5–5.3 GiB；完整 11.2 秒样音合成约 21–22 秒。常驻只省去重复加载，不会使合成自动变为实时。
- SenseVoice int8 听写独立按需加载，CPU 推理，空闲约 3 分钟释放。不受播报常驻开关影响。麦克风仅在显式开始听写后开启，结束即关闭。

## 可选遥控器

- 先通过 Windows 配对。遥控器能输出键盘按键时，在「遥控器按键映射」录入并启用；默认关闭，不影响键盘鼠标。
- 呼出对话、开始／结束听写、发送当前草稿、朗读此条、停止播报、打开工作台，这六项都有独立的全局快捷键和遥控器映射。新增加的遥控器键位留空，已有映射保留；录入后点「保存设置」。无需遥控器也可使用上述快捷键。
- 使用短按切换；连续连发会被忽略，下一次操作前请松开同一按键约 1.2 秒。听写采用按一次开始、再按一次结束，不是按住说话。录入键位期间暂停全局操作，避免学习到的按键立即触发发送或录音。
- 映射对所有键盘设备生效，首版不是设备专属驱动。日常快捷键使用组合键或功能键；可选遥控器映射支持录入单键，启用后会占用普通键盘的同名键。Esc 取消录入、Backspace/Delete 清除映射。
- 工作台支持 Tab、方向键与 Enter。录音使用电脑麦克风，不接遥控器内置麦克风。
- 快捷键冲突会显示提示，可更改映射；系统托盘一直提供对话、工作台、听写和退出入口。

## 退出与数据

窗口 × 只收起窗口。右键托盘 →「退出桌面伙伴」退出壁纸、CLI 及语音进程。原 Windows 壁纸会重新显露。当前运行任务会尝试停止，文件与对话不删除。

壁纸保留已验收的 3840×2400 原画超分素材和原有 Live2D 网格动作。实际绘制按屏幕物理分辨率，未增加大幅动作。默认不设置开机自启。

高级启动参数：`--storage=绝对目录` 指定应用状态目录，`--project=绝对目录` 指定首次项目。公开安装版只提供雨夜壁纸，不包含旧 Hiyori 悬浮人物。正常启动不开调试端口。
