# Rin 完整姿态

六幅完整人物图共用一幅固定房间背景和桌面前景，坐标为 1586×992。`attention` 看向你，`cup` 持杯休息，`work` 专注工作，`thinking` 托腮思考，`window` 看向窗外。`reply-thinking` 是等待回复时使用的新绘制透明原画，人物垂眼看屏幕、指尖轻抵下唇，配有单独生成的闭眼帧。手臂、手和躯干作为完整人物画面渲染。

普通切换约 2.8 秒：当前人物用 1.1 秒分解成马赛克方块并完全消隐，停顿 0.1 秒，再用 1.6 秒重组新姿态，带轻微青色网格光。对话中的思考和回看使用约四分之一秒的淡变。背景和桌面保持不动，所有姿态都有局部眨眼和微小视线变化。朗读时显示音量口型。暂停冻结画面，系统减少动态效果时直接换姿态并保留口型。

`scene.png` 为原有完整 3840×2400 回退原画，属于超分素材。`poses.json` 记录各脸部裁剪和表情区域。格式 4 清单记录运行资源的字节数和 SHA-256；打包只复制白名单、清单和本说明，不包含原画工作目录、旧骨骼素材或生成记录。渲染为自有 WebGL2 实现，不使用视频、LivLiv 或 Cubism 运行库。

普通构建直接使用本目录。重建需要原画 `assets/stills/female-v2`（托腮使用 `assets/stills/scene-v3/thinking.png`）、原画表情与前景、`artwork/rin-poses-v1` 中的蒙版和配准素材，以及 `artwork/rin-reply-thinking` 中的新思考原画和闭眼图。运行 `npm run art:pose-avatar -- --run`，检查 `work/qa/pose-authoring` 本次运行的合成预览后加 `--install` 更新运行文件。`--reply-thinking-only` 会先校验保留素材的清单，再单独更新对话思考素材。`npm run qa:poses -- --run` 检查完整姿态、表情、透明度中点和连续切换，输出位于忽略的 `work/qa/pose-visual`。

原画、透明蒙版、背景补全和表情由生成式图像工具制作。本项目允许随本应用展示、修改和再分发这些文件，不声称对生成内容享有排他版权，不表示任何现有动漫作品或厂商的官方授权。渲染与交互代码遵循仓库 MIT 许可。未使用 LivLiv 示例角色或此前独立头部素材。
