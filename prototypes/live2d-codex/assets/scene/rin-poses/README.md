# Rin 完整姿态

五幅完整人物图共用一幅固定房间背景和桌面前景，坐标为 1586×992。`attention` 看向你，`cup` 持杯休息，`work` 专注工作，`thinking` 托腮思考，`window` 看向窗外。人物的 RGB 保留原画，仅以配准后的透明蒙版分离背景；手臂、手和躯干不拆分、不变形。杯子包含在对应姿态内，淡出时与人物一起消失。

切换约 2.8 秒：当前人物用 1.1 秒分解成马赛克方块并完全消隐，停顿 0.1 秒，再用 1.6 秒重组新姿态，带轻微青色网格光；不叠加两套半透明人物。背景和桌面保持不动，中间可短暂看到空座椅。所有姿态都有局部眨眼和微小视线变化；朗读时先切到看向你，再显示音量口型。没有连续取杯、喝水、挥手、头部转动、呼吸或发丝动作。暂停冻结画面；系统减少动态效果时直接换姿态，保留口型。

`scene.png` 为原有完整 3840×2400 回退原画，属于超分素材。`poses.json` 记录各脸部裁剪和表情区域。格式 4 清单记录运行资源的字节数和 SHA-256；打包只复制白名单、清单和本说明，不包含原画工作目录、旧骨骼素材或生成记录。渲染为自有 WebGL2 实现，不使用视频、LivLiv 或 Cubism 运行库。

普通构建直接使用本目录。重建需要原画 `assets/stills/female-v2`（托腮使用 `assets/stills/scene-v3/thinking.png`）、原画表情与前景，以及私有原画目录 `artwork/rin-poses-v1` 中的透明蒙版、背景补全、闭眼图和配准数据。运行 `npm run art:pose-avatar -- --run`，检查 `work/qa/pose-authoring/assets` 中的合成预览后加 `--install` 更新运行文件。Sharp 只做裁剪、尺寸转换、蒙版配准与合成。`npm run qa:poses -- --run` 检查完整姿态、表情、透明度中点和连续切换，输出位于忽略的 `work/qa/pose-visual`。自动检查不代表审美或长期实机验收。
