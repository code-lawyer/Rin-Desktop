# Rin 分层动态角色

此目录是已停用的骨骼实验素材，仅为保留原始工作和表情、前景来源而存在。当前主应用与打包使用相邻的 [`rin-poses`](../rin-poses/README.md) 完整姿态目录；下文为本目录制作工具的说明，不代表当前应用具备这些连续动作。

以项目原有的雨夜坐姿原画为基准，使用统一的 1586×992 坐标。人物臀部、腿、椅子和桌面保持固定；上身、手臂、手和杯子按预设动作运动。完整回退原画为超分 3840×2400，不声称原生 4K。

`scene.png` 是未经本轮重新生成的完整回退原画；`base.png` 补全上身及杯子后方的场景；`bodyFront.png` 保留原画面部与重新补全的上身。手臂、手、杯子和前景分别保存，`rig.json` 记录其位置和骨骼连接。`blink.png`、`halfBlink.png`、`mouth.png` 来自同一脸部裁剪，只取眼睛和嘴部；`cover.webp` 用于选择卡片。格式 3 清单记录全部运行文件的字节数和 SHA-256，打包按白名单复制并校验几何、贴图尺寸和哈希，不携带原画工作目录或其他人物模型。旧 `half-blink.png` 仅保留兼容源文件，不载入或打包。

运行使用自有 WebGL2 分层渲染、手臂骨骼、原面部纹理的有界网格变形及表情帧。五个状态对应打字、拿杯喝水、托腮、转头看窗外和看向你；四个单次动作是点头、摇头、歪头和挥手，结束后恢复所选状态。手掌在转到侧面时切换到所需动作的绘制层，不混合成两只半透明手。杯子从桌面取起并放回，状态切换等待放杯和收手。眨眼、呼吸、发丝与音量口型同时运行。转头范围受单张面部纹理限制，不提供背面、站立或自由三维动作。暂停冻结画面；减少动态效果停用连续和单次动作，保留朗读口型。运行无需摄像头、在线服务、LivLiv 或 Cubism 运行库。

普通构建直接使用此目录。重建素材使用根目录 `npm run art:action-avatar -- --run`，输出到忽略的 `work/qa/action-authoring/assets`；检查后加 `--install` 写入本目录。需要原画 `assets/stills/female-v2`、完整 4K 回退图、`artwork/rin-scene-v2` 表情，以及 `artwork/rin-actions-v3` 中同画风姿态、背景补全、透明上身和配准坐标。生成记录留在原画工作目录，不作为运行资源发布。`npm run qa:actions -- --run` 生成连续动作样片、表情帧并比对腿、座位和远处场景的固定区域；该检查不代替动态美术验收或实机长时间运行。

场景、动作和表情使用生成式图像工具制作。本项目允许随本应用展示、修改和再分发这些文件，不声称对生成内容享有排他版权，不表示任何现有动漫作品或厂商的官方授权。渲染与交互代码遵循仓库 MIT 许可。没有使用 LivLiv 示例角色或此前独立头部的素材。
