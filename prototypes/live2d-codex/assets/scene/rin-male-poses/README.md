# 动漫男版原画

六幅 1586 × 992 透明人物原画共用同一把椅子和雨夜房间。工作、持杯、托腮、看向窗外和看向你可手动选择。`reply-thinking` 为等待回复时自动出现的指尖抵唇姿态。男版和女版共用 WebGL2 渲染器、约 2.8 秒的像素重组、对话淡变、眨眼、轻微视线活动和朗读口型。

使用历史提交 `fc27bdf` 的男版雨夜「工作」整景作为坐姿母版，沿用原来的「看向你」原画。内置 ImageGen 在同一透视下制作另外四个动作、空椅背景、人物蒙版与局部表情。六幅画共享坐垫上的落座位置、双腿和笔记本屏幕坐标。右侧扶手与毯子是固定前景，在转场中仍遮住人物靠椅内的一侧。蒙版提供透明度，人物的颜色取自整景原画。`scene.png` 是合成原画经 Real-ESRGAN 与 Lanczos 混合制成的 3840 × 2400 回退图，`cover.webp` 是设置页预览。

`poses.json` 记录局部表情的坐标，格式 4 `manifest.json` 锁定发布文件的字节数和 SHA-256。本项目允许随应用展示、修改和再分发这些生成场景，不主张排他版权。渲染和交互代码遵循仓库 MIT 许可。
