# 女生两态动态壁纸

四段视频和两张回退图片来自同一条15秒720p生成母片，制作于2026-10-27。人物为项目生成的虚构成年角色；复用本项目已生成、已上传的工作参考帧，未使用第三方壁纸视频。制作工具为Dreamina Canvas CLI的Seedance 2.0首尾帧模式，按用户批准的单条上限只提交一次。

原片SHA-256：`5fb2e6f1e49145e955cfde1568f573d15673011577a3b294c411174c1dbd09c4`。原片1280×720、361帧，统一使用已有Real-ESRGAN x4plus后缩至3840×2160；无脸部修复、补帧或倒放。4K是超分成品，不是原生4K细节。
