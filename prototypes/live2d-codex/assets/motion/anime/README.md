# 动漫动作视频实验素材

本目录保留十段视频、三张首尾姿态和透明窗雨图层，供更换模型或后续研究参考。现有视频的眼部漂移未通过实机视觉验收，正式入口已恢复为动漫原画姿态与真人视频，不再加载本目录。

视频保持 1024 × 640、24 fps、无声；窗雨位于原始坐标系的 610 × 528 区域。媒体保存在本机，不进入 Git 或构建包。`manifest.json` 仅记录媒体参数和 SHA-256，不含生成提示词、任务记录和账户响应。需恢复实验副本时可使用：

```powershell
npm run art:anime-video -- --run --source=<交付目录>
```

导入会校验全部媒体，已有不同文件不会覆盖；导入不会重新启用正式动漫视频入口。素材原图和生成源文件保持原位。

工作台只提供「动漫静态」五姿态与「真人视频」。旧 `animePlayback: video` 设置会兼容为 `poses`，不改变有效声线、项目、草稿或已有真人风格选择。
