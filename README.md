# Rin Desktop

把 Codex 放到 Windows 桌面的 4K 雨夜壁纸中。用对话气泡发送任务，在工作台管理本地项目与对话，也可以按需启用中文听写、回复朗读和小米遥控器按键映射。

**[下载安装包](https://github.com/code-lawyer/Rin-Desktop/releases/latest)** · [快捷键](#快捷键) · [常见问题](#常见问题)

首次使用按下面的 1–4 步操作。文字对话准备好后就能使用，语音功能可以稍后再开启。

## 使用前准备

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，x64；当前版本面向单屏使用 |
| 账号 | 已具备 Codex 访问权限的 ChatGPT 账号 |
| Codex CLI | 在 Windows 中自行安装，并使用 ChatGPT 账号登录 |
| 内存 | 建议 16 GB；只用文字、听写或轻量播报无需独立显卡 |
| 网络 | Codex 对话需要联网；首次下载语音模型需要能访问 Hugging Face 等上游服务 |
| Qwen 播报（可选） | NVIDIA 显卡，建议 8 GB 显存，驱动兼容 CUDA 12.8；首次准备建议预留约 20 GB 磁盘空间 |

**安装包不包含 Codex CLI 和语音模型。**CLI 由你准备；需要语音时，在应用里点击按钮下载对应模型。

## 1. 准备 Codex CLI

已在 Windows 中安装 CLI，并使用 ChatGPT 账号登录的用户，可以直接进入第 2 步。

### 安装

在 Windows 开始菜单搜索并打开 **PowerShell**，使用当前 Windows 用户运行 OpenAI 官方安装命令：

```powershell
irm https://chatgpt.com/codex/install.ps1 | iex
```

按提示完成后，关闭并重新打开 PowerShell，确认能显示版本号：

```powershell
codex --version
```

安装方法来自 [OpenAI 官方安装说明](https://learn.chatgpt.com/docs/config-file/environment-variables#installer-variables)。已有 Node.js / npm 的用户，也可按 [Codex CLI 官方指南](https://learn.chatgpt.com/docs/codex/cli) 选择 npm 安装方式。

### 登录并确认

在 PowerShell 中运行：

```powershell
codex login
```

在打开的官方网页中完成 ChatGPT 登录。然后检查登录状态：

```powershell
codex login status
```

确认登录方式为 ChatGPT 后，再启动 Rin Desktop。应用沿用当前用户的 CLI 登录；通常无需重复登录，也无需另填 API Key。登录方法见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/auth#sign-in-with-chatgpt)。

本应用连接的是 **Windows 原生 Codex CLI**。请在 Windows PowerShell 中完成上述操作，WSL 中的 CLI 不适用于本版。已有 Codex 桌面版的用户，也请用上面的命令确认 CLI 已准备好。

## 2. 安装并打开 Rin Desktop

1. 打开 [最新应用版本](https://github.com/code-lawyer/Rin-Desktop/releases/latest)。
2. 在 **Assets** 中下载文件名以 **`Setup.exe`** 结尾的安装包，当前为 `Rin-Desktop-0.3.1-Setup.exe`，约 259 MB。普通用户只需下载这个文件。
3. 双击安装，按向导完成操作。
4. 从 Windows 开始菜单打开 **Rin Desktop**，桌面会显示雨夜壁纸。
5. 按 **Ctrl+Alt+空格** 呼出对话气泡。

CLI 已安装但尚未登录时，也可以点击气泡中的「在浏览器登录 ChatGPT」完成登录。

正常使用时只需保持 Rin Desktop 运行，准备 CLI 时打开的 PowerShell 窗口可以关闭，Codex 桌面版也无需保持打开。安装器目前尚未代码签名，Windows 可能显示未知发布者。

## 3. 选择项目，开始第一段对话

1. 按 **Ctrl+Alt+P** 打开项目与对话工作台。
2. 点击左侧「项目」旁的 **＋**，选择你希望 Codex 工作的本地文件夹。
3. 在该项目中点击「新对话」，或从列表中选中已有对话，点击「继续这段对话」。
4. 回到气泡，在输入框中填写任务，点击「发送」或按 **Enter**。需要换行时按 **Shift+Enter**。

例如，第一次可以发送：

> 看看这个文件夹里有哪些内容，先介绍一下，不要修改文件。

后续追问会延续当前对话。气泡显示当前轮回复；要查看完整历史、切换项目或继续另一段对话，打开工作台即可。当前任务执行期间可以查看历史，切换对话需等任务结束或先停止。

拖动气泡顶部可以移动窗口；长回复可点「展开阅读」。遇到授权提示或需要回答的问题时，在气泡中处理。

## 4. 按需下载语音模型

只用文字对话时，可以跳过这一步。

打开 **工作台 → 语音与按键 → 本地语音模型**，按自己的用途选择：

| 你想做什么 | 下载哪个模型 | 大致下载量 | 运行条件 |
| --- | --- | ---: | --- |
| 对着麦克风说话，转成输入文字 | 中文听写 · SenseVoice | 240 MB | CPU 即可 |
| 使用较轻量的回复朗读 | 轻量播报 · Kokoro | 215 MB | CPU 即可 |
| 使用中文女声朗读回复 | 自然女声 · Qwen3-TTS | 模型 4.52 GB，首次另需约 3.3 GB 运行依赖 | 兼容的 NVIDIA 显卡，建议 8 GB 显存 |

不用把三个模型都下载。需要听写就下载 SenseVoice；需要朗读时，再选择一种播报模型。

### 下载、载入与释放

1. 点击对应模型旁的 **「下载并载入模型」**。
2. 面板会显示下载百分比、已下载体积和进度条。可以点击「取消准备」，稍后继续下载，已下载的内容会复用。
3. 下载完成后，应用会校验文件并载入模型。Qwen 首次使用还会准备独立的 Python 和依赖，这一阶段显示状态与活动进度条，请等待完成。
4. 已下载的模型后续可以点击 **「载入模型」**，无需重复下载。用完点击 **「释放模型」**，会释放占用，保留本机文件。

模型直接从 Hugging Face 下载。Qwen 的运行环境从 Astral、PyPI / PyTorch 等上游准备，无需自行安装 Python；缺少微软运行库时，可能需要一次 Windows 管理员确认。普通启动不会自动下载模型。准备完成后，听写和合成在本机运行；Codex 对话仍然需要联网。

### 使用听写

1. 在「语音与按键 → 本地听写」中选择电脑麦克风。
2. 回到气泡，点击「听写」或按 **Ctrl+Alt+V** 开始说话。
3. 再按一次结束，等待识别文字填入输入框；按 **Esc** 可以取消录音。单次最长 60 秒。
4. 检查、修改文字后，点击「发送」或按 **Ctrl+Alt+Enter** 提交。

听写不会自动发送。麦克风只在开始听写后开启，结束后关闭。听写模型空闲后会释放，下一次使用时按需载入。

### 使用回复朗读

回复完整后，默认会响一次提示音。**提示音不需要加载播报模型，也不代表已经开启自动朗读。**

载入播报模型后，点击气泡里的 **「朗读此条」**，或按 **Ctrl+Alt+R**。应用会先准备完整音频，再连续播放；长回复和 Qwen 合成可能需要等待。气泡收起时也可以用快捷键朗读。按 **Ctrl+Alt+S** 停止声音、合成及待播放请求。

在「语音与按键 → 回复播报」中还可以选择：

- **常驻加载播报模型**：开启后保留模型，便于继续朗读；会记住选择，后续启动载入已有模型。下载并载入播报模型也会开启常驻。关闭开关或点击「释放模型」即可释放模型占用；「停止播报」只停止当前朗读。
- **自动播报每条完整回复**：默认关闭。开启后，新回复准备完成便会自动播放。
- **回复完成后提前准备语音**：默认关闭。开启后会提前合成，供之后按朗读键播放；提前准备本身不会自动发声，会占用本机算力。

只想使用文字或听写时，可以保持播报模型未加载。Qwen 常驻会持续占用内存与显存，需要时再开启即可。

## 快捷键

以下为默认全局快捷键，气泡收起时也可使用。听写键会呼出对话窗口。

| 操作 | 默认快捷键 |
| --- | --- |
| 呼出 / 收起对话气泡 | Ctrl+Alt+空格 |
| 打开项目与对话工作台 | Ctrl+Alt+P |
| 开始 / 结束听写 | Ctrl+Alt+V |
| 发送当前草稿 | Ctrl+Alt+Enter |
| 朗读当前完整回复 | Ctrl+Alt+R |
| 停止播报 | Ctrl+Alt+S |

在气泡输入框内，**Enter** 发送，**Shift+Enter** 换行。发送快捷键只提交当前草稿，不会代替你批准授权请求。

要修改快捷键，进入 **工作台 → 语音与按键 → 全局快捷键**，点击对应输入框，按下新的组合键，再点「保存设置」。快捷键被其他程序占用时，面板会显示提示；仍可通过托盘和界面按钮操作。每次使用请短按并松开，再次触发同一操作前留出约 1.2 秒，避免连发被忽略。

## 小米遥控器（可选）

全部功能都可以用普通键盘和鼠标操作，遥控器只提供额外的按键入口。

1. 先在 Windows 中配对遥控器，确认它能够输出键盘按键。
2. 打开 **工作台 → 语音与按键 → 遥控器按键映射**。
3. 点击操作对应的输入框，再按希望映射的遥控器按键。可映射呼出气泡、打开工作台、听写、发送、朗读和停止播报六项操作。
4. 勾选「启用额外按键映射（可选）」，点击「保存设置」。

听写采用按一次开始、再按一次结束。录音来自电脑麦克风，当前不接入遥控器内置麦克风。映射对所有键盘设备生效，启用单键映射后也会占用普通键盘的同名键；未识别到遥控器按键时，可继续使用普通快捷键。

## 打开、退出、升级与数据

- **打开**：从 Windows 开始菜单启动 Rin Desktop。运行后，点击任务栏右下角的托盘图标，或按 Ctrl+Alt+空格打开气泡；图标可能在「显示隐藏图标」中。
- **收起窗口**：气泡或工作台右上角的 × 只收起窗口，壁纸和后台服务继续运行。
- **完全退出**：右键托盘图标，选择「退出桌面伙伴」。应用会退出壁纸及其启动的后台进程，原 Windows 壁纸会重新显露。
- **升级**：从 [最新应用版本](https://github.com/code-lawyer/Rin-Desktop/releases/latest) 下载新安装包并安装。升级和卸载保留个人数据；Codex CLI 由用户单独维护。
- **旧版迁移**：在「语音与按键」点击「使用已有数据目录」，选择旧的 `workspaces.json` 所在文件夹，按提示重启，即可沿用项目入口、会话、草稿和设置。

应用数据默认保存在 `%LOCALAPPDATA%\VibeVoice`，目录名称为兼容旧版本保留。Codex 的登录和会话还由 CLI 在其用户目录中管理。项目文件保留在你选择的本地文件夹中，更多说明见 [隐私与数据](docs/privacy.md)。默认不开机自启。

## 常见问题

| 遇到的问题 | 处理方法 |
| --- | --- |
| 提示「未找到 Codex CLI」 | 在新开的 Windows PowerShell 中运行 `codex --version`。确认安装的是 Windows 原生 CLI；安装或更改 PATH 后，退出并重新打开 Rin Desktop。自定义安装位置可将用户环境变量 `VIBE_CODEX_BINARY` 指向 `codex.exe` 的完整路径。 |
| 终端已登录，气泡仍要求登录 | 用 `codex login status` 确认是当前 Windows 用户的 ChatGPT 登录。本版使用 ChatGPT 账号接入，按气泡中的「在浏览器登录 ChatGPT」完成登录。 |
| 快捷键没有反应 | 通过托盘打开工作台，在「语音与按键」查看冲突提示，更换组合键并保存。连续操作时请先松开按键，再间隔约 1.2 秒重试。 |
| 语音模型下载失败或未完成 | 确认网络能访问 Hugging Face 和相关上游；恢复网络后继续下载。Qwen 的「准备语音运行环境」阶段也需要联网，活动进度条表示仍在准备。面板显示失败后可重试。 |
| 听写没有声音或没有文字 | 确认已下载 SenseVoice，选择了正确的电脑麦克风，并在 Windows 的麦克风隐私设置中允许桌面应用访问麦克风。按一次开始、再按一次结束，等待识别完成。 |
| 听到提示音，但没有朗读回复 | 先载入播报模型，再点击「朗读此条」或按 Ctrl+Alt+R。需要每轮自动朗读时，开启「自动播报每条完整回复」。 |
| Qwen 载入失败或朗读等待较久 | 检查显卡、驱动、显存和磁盘空间；长回复合成也更慢。没有兼容 NVIDIA 显卡时，可使用 Kokoro 轻量播报，文字对话和 SenseVoice 听写仍可用。 |
