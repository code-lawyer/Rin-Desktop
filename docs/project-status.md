# 当前项目状态

当前候选版本为 [0.6.3-rc.7](https://github.com/code-lawyer/Rin-Desktop/releases/tag/v0.6.3-rc.7)。动漫静态壁纸新增人物点击和托盘姿态切换，使用独立安装和数据目录供 Windows 测试。下载页同时提供安装器与第三方对应源码，构建资源按仓库清单单独校验。

当前源码已兼容仅声明 `sessionCapabilities.resume` 的 ACP Agent：优先 load 回放，否则 resume 恢复原上下文并保留本机显示缓存；能力不足、恢复失败与认证错误分别提示。本机缓存不作为远端送达证据，不确定发送仍保留原稿。离线协议回归覆盖连续重连、消息及完成状态、失败时存储保护和其他 ACP Agent 的 load 路径；这项修复纳入 0.6.3-rc.4；真实 Agent 多轮上下文、GUI 完整退出重开和系统重启仍待独立验收。

当前 Agent 页统一展示内置与自定义 Agent，提供连接状态、连接/重连和自定义配置管理；侧栏“选择与管理”直达同一页面。合成界面验证覆盖内置切换、会话恢复失败提示、连接后焦点恢复、表单保存错误可见性、工作中保护、未保存编辑保留及自定义配置损坏时切回内置 Agent，布局覆盖常规和窄窗口；真实 Agent 账户与硬件验收仍需单独进行。

当前源码提供「动漫静态」原画和「真人视频」两种壁纸。动漫 H3 动作视频因实机眼部漂移未达到视觉要求，已从正式入口和构建包撤下；本地试验素材与提示词保留。旧动漫视频设置在读取时兼容为原画姿态，不覆盖原始存储文件，后续正常保存会记录兼容结果；已有真人选择、有效声线、项目和草稿保留。该回退纳入 0.6.3-rc.5 候选安装器。

动漫原画使用 1586 × 992 贴图、超分 3840 × 2400 回退图、像素重组与局部表情；真人视频为超分 4K。减少动态效果时直接切换动漫姿态，暂停停止画面与环境音。隔离 Electron 检查使用实际媒体和生产界面，但后端状态为合成输入；不代表真实 Agent 联动、WorkerW 挂载、系统 DPI/锁屏恢复、整夜稳定性或用户最终视觉认可。

原有安装包的标准用户验收已覆盖内部候选安装、注册、升级、卸载，旧正式包与候选的实际启动及数据副本回退；完整真实数据副本哈希、损坏副本恢复和项目/草稿/设置读取通过。Codex 与 Grok 各完成 20 项实际主应用任务、流式中断、历史与重启草稿恢复。原画姿态包完成 30 分钟、270 轮姿态切换及风格往返/暂停恢复，未见 WebGL 错误或堆内存持续增长；这些历史结果不代替当前源码对应新安装包的验收。

Codex/Grok 的实际界面审批允许、拒绝和审批中停止，以及所属 CLI 退出后的重连已覆盖；用测试副本注入未确认发送记录后，能对照真实原生历史核查且不重复发送。Grok 的问题卡自由文本回答通过，Codex 当前默认模式未发出问题工具请求，不能据此勾选其问题卡实测。退出检查按 PID、创建时间及父子关系核对测试应用拥有的进程。

包内 Kokoro 与 SenseVoice 的 CPU 推理、现有 Qwen 的应用内推理已运行；使用的是固定合成音频，没有做麦克风或主观音质验收，识别仍出现个别错字。缺 CLI/模型、下载取消/失败、绘图中断及隐藏子进程 CUDA 的错误路径已验证；后几项使用明确的故障注入，不代替真实无 GPU 或网络环境矩阵。
