# 当前项目状态

当前候选版本为 [0.6.3-rc.1](https://github.com/code-lawyer/Rin-Desktop/releases/tag/v0.6.3-rc.1)，以独立测试安装和数据目录提供下载安装验收，尚未达到完整稳定版验收标准。稳定安装器仍为 [v0.6.2](https://github.com/code-lawyer/Rin-Desktop/releases/tag/v0.6.2)。源码提交与安装包分别核对，不用版本号或单元测试替代安装器验收。

此前的动漫骨骼动作未通过视觉验收，已从主应用路径停用。当前采用五套完整人物姿态，通过约 2.8 秒的像素分解、重组切换；背景与家具固定，只在脸部局部绘制眨眼、视线和口型，不再通过拼接手臂或头部变形连接大姿态。切换逻辑、真实 WebGL 像素约束和隔离主界面验证已覆盖；这表示方案可验证，不等于用户已认可美术效果或完成发布验收。

| 能力 | 当前范围 |
| --- | --- |
| 桌面壁纸 | 源码动漫模式提供工作、持杯、托腮、看窗外和看向你五种完整坐姿，马赛克分解后聚合成新姿态，保留眨眼、轻微视线与朗读口型。唤醒对话时优先看向你，结束后恢复所选姿态。真人两态视频保留，声线独立 |
| Codex 工作台 | 项目、会话、流式回复、工具审批、问题交互、停止与历史；断线切项目会立即清空旧会话视图并隔离迟到响应 |
| 本地语音 | SenseVoice 识别、Kokoro 朗读；可选 Qwen GPU 方案，模型按需准备 |
| 数据保护 | 分目标草稿、原子保存与备份；发送回执不明时保留原稿，核查前不自动重发 |
| Claude / Grok / OpenCode V2 | 保持实验标识。Grok 已完成本机真实账户协议检查和 20 项主应用任务；Claude 缺少受支持认证，OpenCode 本机尚无已认证模型，各家的完整验收矩阵仍须分别记录 |
| RC003 | 原生组件、连接、按键与录音路径已接入；实机稳定性仍待验收 |

动漫以 1586×992 原画坐标制作完整人物透明贴图，杯子随对应姿态一起像素化消隐；完整回退图为超分 3840×2400，真人视频为超分 4K。人物贴图保留原画 RGB，生成透明蒙版经配准后仅用于分离背景，各姿态分别制作闭眼表情。所有手、肩、腿的形状由原画决定，运行时不生成新的肢体动作。没有连续取杯饮水、挥手、点头、呼吸或发丝摆动；表情仅提供眨眼、轻微视线和注视姿态下的音量口型，不做音素识别。减少动态效果时直接切换完整姿态，停止待机表情，保留口型；暂停则冻结画面。自动截图、隔离渲染和短时播放不等于物理 4K 显示、审美认可或长时稳定性验收。新功能由候选包提供，不改变已有的 0.6.2 安装器。

本机标准用户验收已覆盖内部候选安装、注册、升级、卸载，旧正式包与候选的实际启动及数据副本回退；完整真实数据副本哈希、损坏副本恢复和项目/草稿/设置读取通过。Codex 与 Grok 各完成 20 项实际主应用任务、流式中断、历史与重启草稿恢复。实际包完成 30 分钟、270 轮姿态切换及风格往返/暂停恢复，未见 WebGL 错误或堆内存持续增长；这不等于整夜运行或系统桌面恢复验收。

Codex/Grok 的实际界面审批允许、拒绝和审批中停止，以及所属 CLI 退出后的重连已覆盖；用测试副本注入未确认发送记录后，能对照真实原生历史核查且不重复发送。Grok 的问题卡自由文本回答通过，Codex 当前默认模式未发出问题工具请求，不能据此勾选其问题卡实测。退出检查按 PID、创建时间及父子关系核对测试应用拥有的进程。

包内 Kokoro 与 SenseVoice 的 CPU 推理、现有 Qwen 的应用内推理已运行；使用的是固定合成音频，没有做麦克风或主观音质验收，识别仍出现个别错字。缺 CLI/模型、下载取消/失败、绘图中断及隐藏子进程 CUDA 的错误路径已验证；后几项使用明确的故障注入，不代替真实无 GPU 或网络环境矩阵。

尚待完成：RC003 至少 100 次录音、50 条短语、200 次操作及 IME/键盘共存、音量与休眠重连；Claude 与 OpenCode 配置认证后的真实任务，以及各 CLI 矩阵尚未覆盖的交互；Windows 系统 DPI/锁屏/Explorer 恢复；新机器安装与持续使用；最终视觉认可、发布范围及许可复核。安装器仍未签名。执行时使用 [验收清单](../tools/release/TEST-ACCEPTANCE.md)，没有证据的栏位保留未测。

主应用保留 `prototypes/live2d-codex` 路径，源码默认数据为 `work/runtime/avatar`。模型、runtime、原始美术和私人 Dots 不进入公开源码。可复用验证在 `tools/qa` 与 `tools/probes`，运行输出在忽略的 `work/qa`。独立 `prototypes/video-companion` 的播放器仍被当前动态壁纸复用，不能按旧原型名称整目录删除。

运行 `npm run status` 可查看本机源码、资源和 Git 信息；该命令只读取本地 Git 元数据，不表示已获取远端最新状态。使用与准备方法见 [构建说明](build.md)。
