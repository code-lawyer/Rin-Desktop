# 当前项目状态

当前候选版本为 [0.6.3-rc.13](https://github.com/code-lawyer/Rin-Desktop/releases/tag/v0.6.3-rc.13)。测试版使用独立安装和数据目录，下载页提供安装器与第三方对应源码。

Agent 页提供 Codex、Google Antigravity CLI、Grok Build、Claude Agent 和 DeepSeek Harness。侧栏「选择与管理」可直达。连接错误显示在对应选项旁。保存选择失败时继续使用当前连接。旧 OpenCode 或自定义 Agent 的选择回退到 Codex，旧配置、会话记录与草稿保存在原数据目录。

ACP 会话按 CLI 能力回放或恢复。仅支持恢复时，历史预览使用本机缓存，回执未确定需在原生 CLI 核对。权限审批会关联工具先前发来的操作和路径，缺少必要详情时自动拒绝。

当前源码提供「动漫女版」「动漫男版」和「真人视频」。男版以历史雨夜整景为坐姿母版，六个姿势共用下半身落座坐标和扶手前景，局部表情按原画配准。旧动漫视频设置在读取时兼容为原画姿态，旧 Live2D 男士设置仍回退到动漫女版。加载保留原始存储文件，后续正常保存会记录兼容结果。已有真人选择、有效声线、项目和草稿保留。

两套动漫原画均使用 1586 × 992 贴图、超分 3840 × 2400 回退图、像素重组与局部表情。真人视频为超分 4K。减少动态效果时直接切换动漫姿态，暂停停止画面与环境音。隔离 Electron 检查使用实际媒体、生产界面和合成后端状态。重做后的男版已在 Windows 11 本机单屏的 2880 × 1800 桌面挂载。长时运行和用户视觉认可待验收。

rc.8 已在 Windows 11 单显示器、系统缩放 150% 下实际安装。桌面挂载到 Progman，人物点击完成五姿态轮换，托盘可以直接选择。强制结束壁纸渲染器后，对话与工作台保持可用，托盘姿态项灰置；重试后桌面和托盘切换恢复。从 rc.7 在同一安装位置升级，分别使用日用版和源码版数据副本，项目条目及在旧版保存的测试草稿均在新版恢复，原数据记录的哈希一致。

原有安装包的标准用户验收已覆盖内部候选安装、注册、升级、卸载，旧正式包与候选的实际启动及数据副本回退；完整真实数据副本哈希、损坏副本恢复和项目/草稿/设置读取通过。Codex 与 Grok 各完成 20 项实际主应用任务、流式中断、历史与重启草稿恢复。原画姿态包完成 30 分钟、270 轮姿态切换及风格往返/暂停恢复，未见 WebGL 错误或堆内存持续增长；这些历史结果不代替当前源码对应新安装包的验收。

Codex/Grok 的实际界面审批允许、拒绝和审批中停止，以及所属 CLI 退出后的重连已覆盖；用测试副本注入未确认发送记录后，能对照真实原生历史核查且不重复发送。Grok 的问题卡自由文本回答通过，Codex 当前默认模式未发出问题工具请求，不能据此勾选其问题卡实测。退出检查按 PID、创建时间及父子关系核对测试应用拥有的进程。

包内 Kokoro 与 SenseVoice 的 CPU 推理、现有 Qwen 的应用内推理已运行；使用的是固定合成音频，没有做麦克风或主观音质验收，识别仍出现个别错字。缺 CLI/模型、下载取消/失败、绘图中断及隐藏子进程 CUDA 的错误路径已验证；后几项使用明确的故障注入，不代替真实无 GPU 或网络环境矩阵。

rc.13 延续未签名预发布方式，新增雨夜深色/晨雾浅色/跟随系统主题切换、桌面气泡与工作台对比度及无障碍改进、打包去除冗余静态底图与 Electron Fuses 加固，以及后端存储队列、Agent 审批与子进程生命周期修复。当前源码提供 Authenticode 正式构建入口，正式候选包仍需要可用的发布者签名、分发许可复核和干净 Windows 的安装、升级、数据迁移、卸载及回退验收。Windows 系统 DPI、锁屏、Explorer 恢复、持续使用与视觉认可待补齐。Codex 及其他 CLI 的未覆盖交互按各自支持范围验收。RC003 的录音、按键、IME 共存、休眠重连矩阵仍未完成。执行时使用 [验收清单](../tools/release/TEST-ACCEPTANCE.md)。

主应用保留 `prototypes/live2d-codex` 路径，源码默认数据为 `work/runtime/avatar`。模型、runtime、原始美术和私人 Dots 不进入公开源码。可复用验证在 `tools/qa` 与 `tools/probes`，运行输出在忽略的 `work/qa`。独立 `prototypes/video-companion` 的播放器仍被当前动态壁纸复用，不能按旧原型名称整目录删除。

运行 `npm run status` 可查看本机源码、资源和 Git 信息；该命令只读取本地 Git 元数据，不表示已获取远端最新状态。使用与准备方法见 [构建说明](build.md)。
