# 当前项目状态

源码基础版本为 0.6.2。已发布安装器见 [v0.6.2](https://github.com/code-lawyer/Rin-Desktop/releases/tag/v0.6.2)；版本号相同不代表源码提交与安装包包含相同补丁。仓库的最新提交与现有安装器分别核对，源码更新后需要重新构建并验收才能发布新安装器。

| 能力 | 当前范围 |
| --- | --- |
| 桌面壁纸 | 动漫五静态姿态、真人工作/看向用户两态动态；男士壁纸已移除，声线独立保留 |
| Codex 工作台 | 项目、会话、流式回复、工具审批、问题交互、停止与历史；断线切项目会立即清空旧会话视图并隔离迟到响应 |
| 本地语音 | SenseVoice 识别、Kokoro 朗读；可选 Qwen GPU 方案，模型按需准备 |
| 数据保护 | 分目标草稿、原子保存与备份；发送回执不明时保留原稿，核查前不自动重发 |
| Claude / Grok / OpenCode V2 | 实验入口及离线协议覆盖；尚未完成各家真实账户与主应用验收 |
| RC003 | 原生组件、连接、按键与录音路径已接入；实机稳定性仍待验收 |

壁纸素材使用 4K 输出，包含由低分辨率原片超分得到的媒体；自动截图或短时播放不等于物理 4K 显示和长时稳定性验收。

尚待完成：RC003 至少 100 次录音、50 条短语、200 次操作及 IME/键盘共存、音量与休眠重连；三家实验 CLI 各至少 20 个真实任务；Windows 系统 DPI/Explorer 恢复；新机器安装、缺 CLI/模型/GPU 与真实数据副本恢复；最终发布范围及许可复核。执行时使用 [验收清单](../tools/release/TEST-ACCEPTANCE.md)。

主应用保留 `prototypes/live2d-codex` 路径，源码默认数据为 `work/runtime/avatar`。模型、runtime、原始美术和私人 Dots 不进入公开源码。可复用验证在 `tools/qa` 与 `tools/probes`，运行输出在忽略的 `work/qa`。独立 `prototypes/video-companion` 的播放器仍被当前动态壁纸复用，不能按旧原型名称整目录删除。

运行 `npm run status` 可查看本机源码、资源和 Git 信息；该命令只读取本地 Git 元数据，不表示已获取远端最新状态。使用与准备方法见 [构建说明](build.md)。
