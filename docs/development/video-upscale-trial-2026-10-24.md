## 本地处理与对比

新增[视频加工工具](../../tools/project/prepare-video-4k.mjs)，复用已存在且哈希与历史记录一致的Real-ESRGAN ncnn Vulkan、x4plus模型和FFmpeg。入口：

~~~powershell
npm run art:video-4k -- --help
npm run art:video-4k -- --run --input=work/qa/example/original-720p.mp4 --id=work-to-user --gpu=1 --tile=512
npm run preview:video-4k -- --run --id=work-to-user
~~~

实际输入文件、任务名称和GPU索引以当前环境为准；示例不代表已存在或已验收。工具不下载模型，输出到新的work/qa/video-upscale/<id>，拒绝覆盖既有输出目录或主应用素材。[独立对比预览](../../tools/project/preview-video-4k.mjs)只在本机回环地址提供已完成任务的四个媒体文件，不公开报告或其他工作区文件。

流程为保留原片及校验哈希、提取原帧、x4plus四倍增强、Lanczos统一缩至3840×2160、编码H.264，保持原帧数与逐帧时间戳。不补帧、不做人脸修复，超分和对比输出静音，原片保留原有音轨。对比视频左侧原片、右侧超分，均显示为1920×1080；另从同一中间帧的无损处理结果生成相同区域的脸部局部对照，区别于最终视频编码后的像素。

源片需是短时、方形像素、16:9、SDR视频。本次源片的帧间隔在1/60秒网格上交替变化，不能简单按24fps或60fps重组；工具用原逐帧时间戳生成序列，检查元数据、序列完整性及输出尺寸/帧数/全部时间戳。97帧全部采用同一x4plus模型和512分块参数。先前的小分块试跑保留为局部实验，不混入最终序列。
