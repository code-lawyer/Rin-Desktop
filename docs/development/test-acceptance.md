# Rin Desktop 测试包验收清单

这是可重复使用的人工验收清单。应用版本见 `resources/app/portable.json`，内部候选另有 `TEST-BUILD.txt`；完整文件哈希见 `manifest.json`。Test ZIP/安装器哈希见包外 `SHA256SUMS.txt`，正式安装器哈希见仓库资源清单。本清单的实机栏初始均为**未测**，由测试者填写；没有勾选不代表通过。

## 先准备

- [ ] 退出日用 Rin Desktop，备份其整个数据目录；使用测试项目，勿让 Agent 修改日用工程。
- [ ] 校验下载/复制后的 ZIP 或 Setup 的 SHA-256 与 SHA256SUMS 一致。
- [ ] 选择一种入口：ZIP 解压后启动 `VibeVoice.exe`；或安装带 `Test` 的 Setup，使用 `Rin Desktop Test` 快捷方式。无需两种同时运行。
- [ ] 确认测试应用默认使用 `%LOCALAPPDATA%/VibeVoice/test-builds/<测试标识>`。旧正式安装及数据仍存在。
- [ ] 双击 `Run-Offline-Checks.cmd`，记录返回结果和报告目录。此步骤不用账户、模型或遥控器；不是下面的实机验收。
- [ ] 在工作台添加一个空的中文路径测试项目。账户、CLI 和语音模型由测试者自己准备，基础包不捆绑私人凭据或模型。

## 数据保护（DATA-01 / DATA-02 / AGT-06）

| 编号 | 操作 | 通过条件 | 结果/证据 |
| --- | --- | --- | --- |
| D1 | 新对话输入草稿，切项目/Agent，再退出重开 | 各目标原稿完整；同名、同 ID 不串用 | 未测 |
| D2 | 首次发送期间继续编辑后续文字 | 已确认原稿清理，后续编辑保留到新会话 | 未测 |
| D3 | 用无害任务，在请求送出后中断测试 CLI 连接，再重连 | 若无法确认则显示“结果未确定”和原稿，重启不会重复提交；仍在运行时先停止再核查 | 未测 |
| D4 | 对 D3 点击“核查发送结果” | 找到可信匹配则确认；找不到或历史不可读则继续保留，不因为历史为空就重发 | 未测 |
| D5 | 对无法判定项先查看原生会话，再选择“我已核对，保留草稿” | 二次确认后只解除保护；原稿可编辑，不立即发送 | 未测 |
| D6 | 将旧数据目录完整复制到新测试位置，在工作台选择副本 | 项目、各家会话入口、草稿、声音/按钮设置保留；源目录文件哈希不变 | 未测 |
| D7 | 临时项目改名/移走，再打开应用；恢复原路径 | 缺失明确提示，旧会话/草稿仍保留，恢复后可继续 | 未测 |
| D8 | 同项目大小写路径/目录联接重复添加 | 不制造同一项目的独立草稿；旧别名不同正文可见且不丢失 | 未测 |
| D9 | 仅在测试数据副本中模拟只读/文件占用后修改设置或草稿 | 明确失败，已有内容仍在；解除占用后保存成功 | 未测 |
| D10 | 关闭应用，损坏测试副本的主记录，使用 Recover-Data 工具恢复到另一个新目录 | 损坏原件不变；先预览，显式执行后副本可读；已有输出目录被拒绝覆盖 | 未测 |

恢复命令（先关闭测试应用；目录占位符需替换为自己的副本路径）：

```powershell
.\Recover-Data.cmd --source="<测试数据副本>" --out="<全新的恢复目录>"
.\Recover-Data.cmd --source="<测试数据副本>" --out="<全新的恢复目录>" --run
```

默认使用上一份已提交 `.bak`；需要检查未提交 `.tmp` 时显式增加 `--from=pending`。恢复可能回到较早状态，始终保留原备份和原生 CLI 历史。目录指针损坏/所指目录丢失时，应用应拒绝改用空白数据；恢复该目录/指针或用 `--storage="<有效测试副本>"` 明确启动。

## RC003 与桌面（REM-05 / REM-06 / UI-01）

- [ ] 在应用遥控器页发现、连接、断开、忘记；错误提示与 Windows 配对状态可理解。
- [ ] 在应用中设置每个按钮功能；重启保留设置；发送键一次只产生一条任务，普通确认键不批准权限。
- [ ] 草稿框中按确认一次发送；左键清空后语音重录；刚清空时右键撤销；切换会话或开始新输入后不能恢复旧草稿。识别中不能清空。
- [ ] 「朗读」入口始终可找到；草稿框中右键朗读，准备完成后播放且可停止。输入、听写提示与播报进度分开。
- [ ] 音量加减键在「刚刚按下」中显示正确按钮，播报音量值与实际声音同步改变；鼠标滑块也可即时调节；重启保留音量。无事件时记录固件及日志，不能只凭组件自检通过。
- [ ] 设置六个分类可用遥控器导航；切换分类保留未保存的字段；展开自定义按钮和模型管理后仍能操作。
- [ ] 听写区域分别显示遥控器麦克风状态和电脑麦克风选择；按遥控器语音键时无需切换电脑麦克风。气泡的「电脑听写」仍使用选定电脑麦克风。
- [ ] 仅连接不显示已收音；按住语音键后看到打开麦克风、收到声音及累计时长，松开后才进入本地识别；没有音频时显示可操作的失败原因。停止播报不能清掉录音提示。
- [ ] 遥控器麦克风按住/松开、取消、静音、过短、超过上限、丢释放；识别只写入开始时的目标草稿。
- [ ] 普通键盘与遥控器相同扫描码/近同时输入，中文输入法候选确认、快捷键冲突、快速连发均不误触。
- [ ] 蓝牙断开/重连、设备休眠、电脑睡眠唤醒；旧按键、旧音频或旧识别结果不重放。
- [ ] 按项目既定矩阵完成至少 100 次录音、50 条固定短语和 200 次按键操作；记录失败次数、延迟与复现条件，不只记录一次成功。
- [ ] 壁纸启动、桌面图标、人物切换、气泡焦点、DPI/分辨率、展开阅读、暂停/恢复和退出表现正常。
