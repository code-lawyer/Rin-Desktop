# 技术决策与待决事项

本页区分已采用实现、原设计差异和未解决的产品选择。当前用户目标是“动态壁纸＋Agent＋蓝牙遥控器”，要求保留既有功能、数据和原 GitHub 关系。

## 已采用的路线

| 决策 | 依据 | 后果 |
| --- | --- | --- |
| 保留现有 Electron 主应用 | 当前源码与 0.4.0 已发布实现 | 继续在主应用上集成；不重建 WPF 主界面 |
| 保留主应用现有目录名 | 构建、模型、资源清单、历史工具与本机环境存在引用 | 目录职责明确即可；改名不作为本轮完成条件 |
| CLI 通过结构化接口调用 | Codex RPC、Claude SDK、ACP 源码已存在 | 不采用任意前台粘贴；每家能力以契约与真实验收为准 |
| JSON 索引和持久草稿 | 现行 WorkspaceStore 与 NativeAgent 实现 | 旧 SQLite/仅内存草稿方案归档；隐私说明需反映正文缓存 |
| 本地 SenseVoice/Kokoro/Qwen | 既有发布和语音实现 | 保留按需准备、独立 worker；不隐式云回退 |
| RC003 原生设备服务接入现有应用 | Raw Input/ATVV 诊断成果与本轮离线接线 | 应用内连接/按钮设置，原生隐藏组件，无 Python 安装；设备矩阵先按 Codex 主线验收 |
| 数据与私人通道保留原位置 | 当前用户明确要求，代码仍有依赖 | Dots、模型、Qwen 旧环境和用户数据不因目录整理搬迁 |
| 同一 Git 仓库持续开发 | 原根目录与 origin 已核对 | 新文档/工具纳入原公共范围；保留历史与发布链 |
| 台账为进度唯一维护来源 | 多时期计划并存导致进度误判 | JSON 生成进度和归并页；CI 检查漂移、缺失项和依赖 |

## 待决事项

**DEC-01：新增后端账户和计费边界。** 2026-10-22 发布检查依据[Anthropic 官方 SDK 说明](https://code.claude.com/docs/en/agent-sdk/overview)，确认未经批准的第三方产品不可提供订阅登录/额度。本项目没有此类批准；0.5.0 将 Claude 标为实验，并要求用户自行配置 API Key 或官方云平台 API 认证，由 CLI 的实际认证类型把关，拒绝纯 OAuth/未知认证，费用提示明确。Codex 登录方式不变，不自动创建或替换任何凭据。这是分发边界修正，不代表用户已同意切换计费；新增后端逐家真实认证及扩大正式支持仍待验收。

**DEC-02：原 TUI 共存和多个后台任务。** 现行产品已采用壁纸气泡与工作台；原 TUI 同任务双客户端控制、最多三个活动任务及同目录并发不是当前已经完成的能力。旧条目保留为待决/后置，不能直接删除，也不能把桌面界面当作该要求通过。决定是否继续投入时，要列出用户收益、协议可行性、隔离策略和验收成本。
