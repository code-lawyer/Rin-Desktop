# 静态壁纸恢复与第一阶段预览

2026-10-22，ART-09。本文保留前两轮独立小样记录。随后已完成六姿态与环境音的主应用接入，当前实现、验证与启动方式见[主应用集成](static-wallpaper-integration.md)；以下「尚未接入」描述均指当时的小样阶段。

## 已完成的源码变更

主应用只加载原画渲染器。工作台移除视频选择和播放控件，主进程不再准备或提供视频媒体，源码启动器拒绝旧视频参数，根 npm 菜单退出视频试用启动。原有男女选择、画面就绪后提交声线、失败保留画面/声线和重试机制保留；遥控焦点样式及导航修复保留。

加载旧工作台数据时，`wallpaperKind: video` 在内存中恢复为 `artwork`，保留有效人物、自定义声线、朗读音量、项目与草稿。读取本身不改写原文件，下次正常保存才落盘；不对历史试用包或正在运行的旧版本做原地替换。现有视频研究及独立实验源码保留，不进入主应用渲染依赖。

原画主应用从根命令 `npm start -- --wallpaper=artwork` 启动。本次未重启用户正在运行的旧试用包，也未制作新的安装包或发布。

## 小样入口与范围

在具有原本地美术资源的工作区执行：

```powershell
npm run preview:stills
```

打开终端输出的本机回环地址。服务只开放明确列出的两张原画、两段本地声音和页面脚本，不提供目录遍历、写接口或工作台数据。源代码见 [预览服务](../../tools/project/preview-stills.mjs)、[页面](../../prototypes/live2d-codex/renderer/still-preview.html)、[切换控制器](../../prototypes/live2d-codex/renderer/still-sequence.mjs)、[环境音试听](../../prototypes/live2d-codex/renderer/ambient-preview.mjs)。

默认显示原工作图，可直接切换原注视图、自动演示、暂停和全屏查看。过渡候选开关、中间图资源入口及透明度叠化均已取消。目标原图解码成功后直接替换画面；失败保图并可重试，快速反向选择采用最新目标，暂停期间保留请求并在继续时执行。

两张原画保持 3840×2400。首轮曾用内置 imagegen 生成 1586×992 的轻抬头候选，未通过 4K 与背景一致性验收。用户实际预览后明确否定过渡图效果，因此候选已退出页面与后续计划；本地文件和提示词只留作历史记录，不再推进候选修正或 T2。

首轮合成声音被用户反馈为过重、不自然，本轮完全替换为小雨与笔记本键盘录音，来源均标记 CC0，见[来源与处理说明](../../prototypes/live2d-codex/assets/ambience/README.md)。雨声经低频/高频处理与环接，形成 60 秒本地循环；键盘以 1.5–2.8 秒真实短句播放，段间停顿 5–12 秒，避免相邻重复。音源分别控制电平并柔化突兀峰值，默认关闭，初始小雨 12%、轻敲 8%。

模拟听写静音、朗读压低、暂停和页面隐藏会改变音量策略。键盘仅在工作图出现，切至注视时停止。录音异步加载期间关闭声音或进入静音状态，加载完成不能重新冒出声音；加载失败保留原画并可再次开启声音重试。这些按钮**只模拟状态**，未调用真实麦克风或 TTS；电脑/RC003 的声音优先级集成、系统锁屏/休眠等仍待后续验证。程序检查不代替用户对音色的实际试听。
