## 视觉基线

- 保留黑色双马尾、红衬衫、雨夜窗边、扶手椅与笔记本的人物和场景辨识度；将六张统一为同一套半写实插画，脸型、眼形、发际线、年龄感和材质一致。
- 先选定一张完整工作姿态母版，从中确定脸部/服装参考和固定场景底板。之后每张都携带同一母版与人物参考，不让参考随逐次生成漂移。
- 镜头、构图、人物尺度、窗框、椅子与电脑位置固定；允许头颈、肩背、手臂和手部进行必要的自然变化。新姿态露出的背景须先补全，头发、袖口和椅背遮挡关系逐张检查。
- 用参考图编辑逐张制作高质量素材。六图并排只用来审看；不把一张六宫格切成最终壁纸，以免每格分辨率不足。

## 六张画面的差异

| 状态 | 需要看得见的差异 |
| --- | --- |
| 专注工作 | 稍向电脑前倾，视线落在屏幕，两手处于输入姿势 |
| 阅读屏幕 | 稍微坐直，手离开输入姿势，一手放在扶手或电脑边缘；脸部朝向仍以屏幕为主 |
| 望窗思考 | 头颈与肩背协调转向窗边，视线明确落在窗外，手放松；幅度不能导致直切时人物大幅跳位 |
| 闭目休息 | 轻靠椅背、闭眼、肩膀和手放松；区别于原工作姿势仅闭眼 |
| 看向用户 | 自然抬头、面向用户，两手停止工作；用于交互 |
| 微笑回应 | 从同套看向用户姿态衍生，柔和闭嘴微笑、轻微偏头；作为互动表情变体验收 |

六张是四种日常姿态与两种互动表达，不要求为了区别而给每张加入新道具或夸张动作。第一组工作/阅读必须靠手与肩背区分，不能主要依靠重新生成的脸部差异。

## 制作和集成顺序

1. **先交三张完整小样：工作、望窗、看向用户。** 用跨度较大的三种方向验证同一个人、同一种画风和正常人体比例。展示整幅与相同倍率的脸部/手部对照，供用户确认后再扩充。
2. **扩充阅读、休息和微笑，整套检查。** 六张共同核对面容、发饰、红衬衫、人物尺度、光照和清晰度。不合格图回到共同参考进行局部返修，不单靠同一段提示词或固定随机数保证身份。
3. **生成完整交付帧。** 将各姿态需要变化的人物区域与同一背景底板离线合成并修整遮挡边缘，输出六张完整画面。运行时不再只裁头部；改为直接绘制已解码的整张帧，否则新手势和上身变化会被当前 `compose()` 丢弃。
4. **统一输出与细节验收。** 目标画布为 3840×2400，并检查统一的 16:9 裁切安全区。内置图像工具可作参考图编辑，但实际生成尺寸必须读取文件确认。原始输出不足时，另做统一放大及局部精修并明确记录；放大版不能称作原生 4K。脸、手、发丝、衣料在最终尺寸 100% 对照，达不到要求就保持待验收。
5. **先预览，再替换。** 新素材放在独立版本中，现有一套可回退。小样一次展示六张缩略图，并提供每张约 5 秒的验收轮播，直接切换；沿用用户已确定的无过渡图、无叠化方式。

## 自动展示建议

美术与规则分别验收。日常仍以工作为主；建议每轮阅读、望窗、休息各出现一次，随机排序，中间回到工作，减少只看到近似状态的机会。停留时间先沿用安静的节奏，再根据实际试看调整。

打开对话/听写时看向用户，完成后微笑；对话收起后恢复闲置计时。长期连接错误只在界面提示，不应永久锁住壁纸姿态。真实采音、朗读的环境音安全优先级保留。

设置页建议提供六张预览、当前姿态与暂停原因，方便分辨素材差异和调度行为；展示模式与日常自动模式明确分开。

## 放行条件

- 六图并排与直接切换时，能认出是同一个人物、同一套画风；面部差异以动作和表情为主。
- 工作/阅读、工作/望窗、工作/休息在普通桌面尺寸就能分辨，不要求用户放大找变化。
- 场景、人物尺度及整体裁切稳定，头颈、肩背和手部自然；没有旧头发残留、袖口断裂、边缘光圈或浮空手。
- 最终像素尺寸和实际细节分别记录。工具支持参考编辑不代表能一次生成六张合格或原生 4K 图。
- 确认全帧切换、失败保图/重试及状态编排后，回归既有对话、工作台、语音和遥控功能。美术满意度由实际预览确认。

本轮建议下一步先制作三张同源完整小样。三张的一致性和动作区分通过后，再投入另外三张及主应用替换，避免重复整套返工。
