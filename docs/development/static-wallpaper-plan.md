# 4K 静态人物壁纸与环境音优化方案

2026-10-22，ART-09。用户已明确决定放弃本轮视频片段方案，回到原有 4K 静态人物壁纸，增加姿态、改善切换并加入轻微环境音。此决定替代 ART-04 至 ART-08 的视频后续制作方向；H3、Wan 和视频超分不再是产品依赖。精细 Live2D 样例也不进入本轮方案。

用户已授权实施，第一阶段完成原画入口恢复和独立小样。试听后用户明确取消过渡图，要求原图直接切换，并将厚重的合成音改为小雨与轻敲键盘。当前计划已按反馈修订，详见[实施记录与预览](static-wallpaper-preview.md)。六种姿态与主应用环境音已接入，当前执行细节、素材分辨率边界和试用方式见[集成记录](static-wallpaper-integration.md)；下表保留设计建议，实际停留参数以集成记录及代码为准。旧候选、研究和试用证据保留，运行中的旧试用版和已发布安装包未被原地替换。

## 已核对的基础

- [人物配置](../../prototypes/live2d-codex/backend/character-profiles.cjs)声明原女生母版为 3840×2400，约 16:10；原男生为 1586×992，不能把两者都称为原生 4K。此次先扩充原女生，男生选项与既有声线行为继续保留。
- [原壁纸渲染器](../../prototypes/live2d-codex/renderer/wallpaper.js)通过原有模型容器承载画面，以 `ParamAttention` 在工作和注视之间过渡，另有手部微动和独立雨滴画布。原雨滴已限定在窗玻璃区域。
- [状态规则](../../prototypes/live2d-codex/backend/wallpaper-state.cjs)目前主要区分 `typing` 与 `attention`，并不具备多姿态编排；现有指数缓动不是新增自然姿态的替代品。
- 两张原女生 4K 图已目视比较：红衬衫、双马尾、扶手椅、膝上笔记本和雨夜窗景为统一的美术基线。本轮不把此前生成的摄影风格视频候选帧混入这套原画。

## 图片数量与制作约束

第一版目标为 **6 张可停留姿态，不再制作过渡图**。现有两张原图先验证直接切换，再扩充其余姿态；每张仍需检查背景、细节和人物一致性。

| 编号 | 姿态 | 画面要求 | 用途与建议停留 |
| --- | --- | --- | --- |
| A | 专注工作 | 原有工作图；视线朝电脑，双手位于键盘 | 主要待机和任务运行姿态，平时可保持 60–120 秒以上 |
| B | 暂停阅读 | 头部略抬，仍看屏幕；手指放松但不移走电脑 | 工作间歇 8–20 秒，连接其他姿态 |
| C | 望窗思考 | 小幅转头和视线移向窗边，肩膀基本保持，禁止扭颈 | 空闲时偶尔停留 12–25 秒；相隔至少约 3 分钟 |
| D | 闭眼小憩 | 与 B 共用头身位置，仅闭眼并放松表情 | 长时间空闲时偶尔停留 3–5 秒，不当作慢动作眨眼 |
| E | 看向用户 | 原有注视图；自然闭口，保持坐姿 | 呼出对话、输入、听写和等待用户确认 |
| F | 轻微微笑 | 与 E 接近，仅表情轻微变化，不夸张张嘴 | 正常回复完成时可短暂停留 2–4 秒，再回 E；错误和审批不触发 |

所有图片共用一张背景底板、同一画布、光照、人物比例与坐标。先从原图做局部编辑，再合回固定底板；不能分别生成八个近似房间。人物移动露出的背景需补全；头发、袖口与椅背的遮挡边缘必须检查。先交付完整 4K 合成图，透明人物层作为可选工程材料，不以重新拆解精细人体绑定为前提。

画布沿用 3840×2400；16:9 屏幕以统一安全区域裁切，所有姿态采用同一规则，保证头部、手和笔记本不被切掉。图片尺寸与真实细节分别验收，不把放大到 4K 尺寸当作新图已达到原画清晰度。原图的脸、眼睛、发丝、手指和红衬衫纹理需做 100% 对照。

## 直接切换与状态编排

按用户反馈，下一张完整解码后直接替换当前图，取消中间姿态和透明度叠化。切换只由明确的交互或低频闲置事件触发；通过一致的构图和足够的停留时间保持安静，不要求用户等待过渡序列。

旧 T1/T2 与 100–200 毫秒叠化建议已取消。不会用光流、网格扭曲或持续推拉镜头模拟两张静态图之间的动作；未通过的轻抬头候选退出小样和后续素材计划。

人物仍然呈现有限的静态姿态变化，不承诺连续转头、真实打字或语音口型。原有手部/呼吸微动需在 4K 屏幕复查，出现形变就关闭；雨滴可作为独立、低幅度的环境变化保留。

| 状态 | 编排建议 |
| --- | --- |
| 无交互待机 | A 为主，间歇到 B；更低频到 C/D，避免循环播放相同顺序 |
| 呼出对话 | 对话立即出现，人物随后转到 E，不等待图片加载才显示界面 |
| 用户输入、电脑或遥控器听写、审批/错误待处理 | E 稳定停留，停止闲置轮换 |
| Agent 实际运行 | 用户未在输入或听写时，回 A/B；状态变化不逐条触发切图 |
| 正常回复完成 | 可用 F 短暂回应，再停在 E；不得用表情替代真实完成/错误文字状态 |
| 收起对话 | 等待约 3–5 秒，再直接回工作图；快速开关不会反复切图 |
| 暂停壁纸 | 固定当前图，暂停雨滴、姿态计时和环境音；原朗读控制继续独立工作 |

调度设最短停留、去重和事件优先级，输入/听写/待确认优先于工作和闲置轮换。快速反向操作合并成最新目标，不把多次切换排成必须播放完的队列。缓存当前图与目标图，先解码成功再替换；新图失败保留当前图，显示重试。姿态变化不修改人物或默认声线；只有真正切换人物且画面就绪时，才沿用现有统一提交入口。

## 环境音

首版只做 **窗外小雨＋轻敲笔记本键盘**。用户已否定第一版的厚重合成音；当前小样改用 CC0 实录、削弱低频和尖锐高频，控制突兀峰值，保留轻微雨点与自然敲击节奏。暂不加雷声、音乐、语气声或大量提示音。

| 声音 | 编排 | 与交互的关系 |
| --- | --- | --- |
| 小雨 | 实录雨点低音量持续播放；当前为 60 秒循环，预处理接缝，多次切图不重新播放 | 全场景维持很低音量；单独开关和调节 |
| 轻敲键盘 | 实录短句保留原节奏，每段约 1.5–2.8 秒，段间停顿 5–12 秒，避免相邻重复 | 仅 A 工作姿态出现；B/C/D/E/F 时停止；不监听用户全局按键，不宣称和静态手指逐键同步 |

环境音有总开关、独立音量与一键静音，正式接入时记住用户选择。小样默认关闭，显式开启后小雨为 12%、轻敲为 8%；音源已单独控制电平，百分比不等于声压或设备音量。许可、原作者及处理方式见[录音来源](../../prototypes/live2d-codex/assets/ambience/README.md)，无需外部壁纸宿主或在线播放服务。

声音优先级建议为：电脑/遥控器采音 > 回复朗读 > 环境音。录音开始前先静音环境音，录音、取消、异常和断线统一释放后再恢复；朗读时停止键盘声，将雨声降低到用户设定的约 20%，朗读结束后约 1 秒平滑恢复。所有恢复动作重新核对当前录音、静音与暂停状态，不能用一个旧计时器把新状态覆盖掉。暂停、退出、锁屏和休眠应停止环境音，唤醒后遵守用户音量和静音选择。

只设一个环境音播放拥有者，气泡和工作台不能各播一份。当前朗读音量及遥控器音量键的用途保留，环境音通过工作台单独设置，仍能由原遥控方向/确认导航操作。图片或音频加载失败各自降级，不阻止文字对话、朗读或听写。

## 实施顺序与验收

1. **退出视频路线并恢复原画入口。** 定向停用视频选择、试用启动和发布依赖；兼容已保存的视频设置，回到原女生或有效的既有人物。保留项目/会话数据、男女选择、默认声线统一入口、重试、语音、播放、遥控焦点等已有修复。先检查工作树差异，再逐模块处理，不用整仓回退。历史源码和研究不要求物理删除。
2. **验证原图直接切换。** 用 A、E 做“工作→看向用户→工作”小样，保持 4K 原图，随后扩充六个常驻姿态。取消 T1/T2，不再把过渡图验收作为前置条件。
3. **调整小雨和轻敲。** 先试听实录音色、循环与音量，再接入并验证电脑和遥控器采音静音、朗读压低、快速取消/重试、暂停和恢复。
4. **完整桌面验收。** 4K 屏幕与常用缩放下连续观察；验证图片解码失败、快速呼出/收起、角色切换、恢复旧设置、暂停/锁屏/休眠、遥控焦点和音量。完成合适的离线/渲染回归后，实际美术、听感、麦克风和物理遥控仍分别验收。

用户已确认放弃视频、转回静态扩充，并进一步取消过渡图。六张常驻姿态为目标，计时和声音参数通过小样再调整；ART-09 继续施工，程序与规则检查不能替代新图和实际听感验收。
