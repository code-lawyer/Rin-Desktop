# 五姿态的场景一致性返修

最新方向：用户仍保留全部五姿态，并允许重新考虑视频；见[一致性与自然衔接方案](five-pose-continuity-plan-2026-10-23.md)。本页保留此前静态返修的定位与失败证据，不代表新路线已完成。

当前结论：用户再次反馈固定场景小样仍有扶手错位、靠背漂移，**小样未通过场景验收**。下述9处区域一致仅是局部检查，不能证明完整家具轮廓稳定。后续需要重做精确分层与遮挡，不能仅把剩余问题归为发丝边缘精修。

用户反馈五张图在切换时沙发变形。检查1586×992生成原图与主应用整帧绘制方式后，确认问题存在于原始美术：尤其托腮图为了支撑肘部，生成了额外抬高的扶手；休息姿态还重绘了靠背、皮革纹理和人物附近的背景。4K超分不修复这些空间关系，代码回归通过也不代表美术验收通过。

## 第二次反馈后的定位

重新检查五张合成图、空房间底图与 `still-scene-compose.mjs`，确认共用一张底图并不足以锁定最终画面的家具：

- 当前人物层是整张姿态图通过一条粗略闭合路径裁切，未定义发丝之间、手臂与躯干之间的透明孔洞。轮廓内仍可能包含原姿态图自己的靠背、扶手和背景。
- 蒙版使用12像素描边和3像素模糊，主动向轮廓外扩展。这样能减轻硬切边，却也会混入旧家具像素，不能作为精确抠图。
- 新生成的空景与各姿态原图不是同一份家具像素。共用腿部区域也带有局部坐垫；其自身虽固定，仍可能与空景结构不衔接。捧杯分支还复制了整块杯碟区域，而非独立杯子。
- 合成顺序只有空景、腿部、人物和杯碟补丁，没有独立的桌沿/近侧扶手前景层及手部遮挡关系。完整轮廓的正确性仍取决于每张源图和粗蒙版。
- 9处抽样区域避开了多数人物边界，遗漏了混入旧家具的位置。其全部通过是必要的局部证据，不能作为这次美术修复完成的证据。

因此，本轮只完成诊断与返工方案修订，没有生成另一批整图、调整模糊参数或宣称家具问题已修复。

## 重做方案：唯一场景与精确人物分层

1. **先冻结唯一家具结构。** 以工作姿态母版的镜头、桌沿、扶手和靠背为坐标基准，已经可见的家具复用原像素；被人物遮挡的部分只补绘一次，检查透视和轮廓衔接后冻结。不能让生成的空景和旧人物图分别定义两套沙发。
2. **真正分离人物。** 每个姿态制作带透明度的人物层，包含手指间、发丝间及手臂内侧的孔洞，并清理边缘夹带的旧背景颜色。在棋盘格及明暗底色上检查，人物层不得夹带沙发或桌面。现有粗路径只能作为初始选区，不能作为最终蒙版。图像生成只提供候选，精确边界需要逐处修整和复核。
3. **明确前后遮挡与接触。** 背景/靠背/坐垫为底层，人物按实际遮挡关系拆分，桌沿及近侧扶手使用同一份前景素材，落在扶手或桌面上的手部放在相应前景之上。所有姿态固定臀部落点、座椅尺度和视角；姿态不贴合这些约束时返修人物，不能移动家具或拉伸脸和身体来适配。工作、捧杯、托腮、看雨、陪伴五个明显动作保留。
4. **背景只加工一次。** 固定场景和前景各自完成一次4K加工后冻结，人物另行处理，最终在同一坐标系输出五张完整3840×2400图片。避免五张成品分别重绘/超分背景后再次产生差异。主应用继续加载完整图片并直接切换，不增加运行时图层逻辑或改变语音、对话框、工作台和遥控行为。
5. **先通过两姿态，再扩到五姿态。** 先用工作与捧杯验证前倾/后靠时靠背显露和手部遮挡；通过完整轮廓检查后，才制作另外三姿态。当前小样不能直接进入4K或覆盖主应用。

## 新验收门槛

- 隐藏人物及独立可动道具后，各姿态工程输出完全相同的固定场景；每张人物透明层单独检查，不允许家具残片或半透明旧背景。
- 全幅差异只能落在经过独立确认的人物、杯子和必要的局部接触阴影范围内。不可用现有粗路径反过来定义所有允许差异的区域，否则会重复漏检。
- 对左右扶手、靠背顶线与两侧轮廓、坐垫边缘和完整桌沿逐段检查。人物可以遮住轮廓；显露出的轮廓必须回到同一条固定参考线上，不能换位置或透视。接触阴影可局部改变明暗，不能改变家具几何。
- 在实际4K输出上做100%局部检查和整幅快速来回切换，检查五姿态两两切换中的双边、跳边、旧纹理、漂浮的手和穿插。不再用几块固定矩形或自动测试通过替代完整美术验收。
