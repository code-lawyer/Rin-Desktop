# 遥控草稿与语音操作整理

2026-10-22，针对内部测试反馈整理对话气泡与工作台，并补全草稿和播报操作。任务为 UI-03、REM-07；当前是源码与离线验证完成，真实遥控器和安装验收仍待补充。

## 用户操作

默认设置下，在对话的草稿输入框中：

| 按钮 | 操作 |
| --- | --- |
| 按住语音键 | 使用遥控器麦克风；松开识别为草稿 |
| 中间确认键 | 一次发送当前草稿 |
| 左方向键 | 清空当前草稿，可继续按语音键重录 |
| 右方向键 | 朗读最新完整回复；刚清空且未编辑时撤销清空 |
| 上下方向键 | 移到其他可见控件 |
| 音量加减键 | 调节应用播报音量，单次按下调整 10% |

这些是草稿框内的操作。工作台、下拉框和权限请求保留导航语义；权限审批仍需要在明确的操作上确认两次。清空、撤销、发送和朗读也可在「自定义按钮功能」中单独分配。已有自定义设置不覆盖；草稿提示随实际映射更新。手动清空只修改当前未发送草稿，不删除会话或已发送内容。

语音识别中、发送结果不确定或权限请求未处理时，不允许清空。撤销只保留本次窗口内的一份清空内容；开始键入、收到新的听写、切换会话后失效，不会把旧文字写进新会话。保存失败沿用已有可见错误和重试机制。

## 界面层级

对话保留现有雨窗配色、半透明气泡、拖动、阅读和项目目标。固定「朗读」入口在回复与草稿之间，播放准备、停止和音量放在同一行；进度不再占据听写提示。草稿区只显示当前录音状态或一行按键提示，清空后显示撤销。

设置分为壁纸、遥控器、声音与听写、对话、键盘、数据六类，只显示当前类别。按钮自定义、模型管理和较长的资源说明默认折叠；已有数据目录入口移入「数据」。切换分类只隐藏节点，保留尚未保存的字段。

## 音量通路与边界

旧辅助程序仅注册键盘 Raw Input，未处理 HID Consumer Control 集合；按钮目录没有音量项，Web Audio 也没有应用音量控制。新实现同时接收键盘式音量键与 Consumer Control 的音量增减，仍要求所选设备容器与 VID/PID 匹配。原始 HID 按描述符解码，未知 usage 不执行动作，同一次按住不重复触发；断开/热插拔清理描述符和按键状态。

实现遵循微软的 [RAWHID 报告结构](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-rawhid)、[GetRawInputDeviceInfoW 描述符读取](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getrawinputdeviceinfow)及 [HidP_GetUsages](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/hidpi/nf-hidpi-hidp_getusages)。没有猜测厂商报告中的字节位置。

播报音频通过 GainNode 输出；屏幕滑块和遥控器动作改变同一个增益，正在播放和之后播放均生效。`settings.playbackVolume` 范围 0–1，旧数据缺省为原来的 100%。独立音量 IPC 只保存该设置，不重载模型或重新注册全局快捷键。系统输出设备、静音及其他应用音量仍由 Windows 管理。

用户已报告旧版音量键没有系统提示或可听变化。新接收路径尚未得到这只遥控器的物理事件验证；如果设备固件不通过蓝牙发送该键，应用无法凭空获取它。可在工作台查看「刚刚按下」，或查看本地脱敏 `event: button` 记录；记录只含被确认的遥控器按钮和功能，不含普通键盘、原始设备 ID、语音或文本。此项仍是 REM-07 / REM-05 的实机待验收范围。

## 验证与交接

本轮只读检查用户刚完成测试的主应用日志，观察到一次 `trigger: key` 的完整链路：113 帧、1695 ms，依次经过 receiving、closing、recognizing、complete，并报告草稿保存完成。这是用户操作产生的一次主应用运行证据，未读取识别文本，也没有据此宣称识别准确率、长期稳定性或新增音量功能通过。

- `npm test` 的完整离线回归通过；随后新增的音量设置持久化及非法值测试也通过。新增覆盖草稿清空/撤销/会话隔离、识别中保护、确认发送、实际映射提示、分类切换保留输入、音量按键代际/去重和播放中增益变化。
- `npm run qa:remote-component` 通过 C# 编译、Consumer Control 按键边沿自检、私有管道握手、依赖复制和 Electron 原生模块加载。不访问设备。
- `npm run qa:interface` 加载实际构建的 renderer，通过合成 preload 检查发送、清空、撤销及布局。完成两轮批量检查；最终 11 张截图覆盖 440/360 DIP 气泡、1120×760 / 760×540 DIP 工作台，以及录音和朗读准备状态。无控件横向溢出或控制台错误。输出在忽略的 `work/qa`，不是实际账户/设备验收。
- 前端构建通过；发布候选由根目录 `package:test` 生成，随包的 `Run-Remote-Checks.cmd` 包含草稿与语音专项。

本轮没有下载模型、迁移用户数据、修改原 GitHub origin、推送或替换正式发布。实机复测按[测试包验收清单](test-acceptance.md)记录，重点是语音键收音、确认发送一次、清空重录、撤销、右键朗读以及音量数值与听感同步变化。
