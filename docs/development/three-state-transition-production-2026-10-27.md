## 独立预览行为

[转场播放器](../../prototypes/video-companion/transition-player.mjs)按当前状态与最新目标选择有向片段。素材准备完成并取得可显示帧后才换画面；已经显示的动作播放到终点，再执行最新目标。未显示的旧加载可以取消，连续改选不会把所有点击排成长队。

到达终点后暂停在解码末帧。手动暂停与页面隐藏独立处理，重新显示页面不会取消用户的暂停。加载、播放、解码失败或长时间停滞时保留先前稳定画面，提供明确重试；错误不自动重复请求生成服务。

[本地预览服务](../../tools/project/transition-preview-server.mjs)仅监听回环地址，只提供页面模块、校验后的素材清单和清单内媒体。支持视频范围读取，不提供运行记录、账户信息或工作区任意文件。

~~~powershell
npm run test:transitions
npm run preview:transitions -- --run --id=<local-bundle>
npm run qa:transitions -- --run --id=<local-bundle>
~~~

`<local-bundle>` 指本地已经准备的 `work/qa/three-state-preview` 子目录；运行预览和离线检查不会生成视频、下载模型或访问账户。[媒体检查](../../tools/qa/transition-media.mjs)导出六条联系表、首尾帧及12种有向接缝对照，结果写入独立的忽略目录。边界差值只辅助定位变化，不证明画质或逐像素锁定背景。
