## 交付与使用

女生可选动态模式包含工作循环、转向用户、用户循环、返回工作四段。它们来自本次获批的同一条15秒720p母片，并使用已有Real-ESRGAN/FFmpeg免费超分为3840×2160。仅按255积分报价提交一次，没有重试生成；报价不冒充钱包结算记录。生成原片、超分母片、逐帧对照、剪辑记录和28.375秒反复往返预览保留在忽略的工作目录。

主应用保留静态五姿态、男生、统一声线提交、对话框、工作台、原语音通道、环境音及遥控导航。已有设置默认维持静态；本次本机试用选择女生动态自动模式。呼出对话时转向用户，结束后返回工作；界面立即响应，人物在安全片段边界跟随。无需Wallpaper Engine、Steam、生成账户或额外运行服务。

## 边界

两态素材仍有雨滴、手指和细微表情差异，不能称逐像素无缝；视频是720p超分4K，超分不能补回真实原生4K细节。用户的最终美术接受度待实际试用，旧五姿态静态图的扶手/靠背问题没有被本次修复覆盖。
