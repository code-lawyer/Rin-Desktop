# 女生五姿态第二版（2026-10-23）

用户要求动作明显、能自然保持在屏幕上，接受工作、捧杯、托腮、看雨和陪伴，并删除靠椅读书。当前已生成五张同源完整画面并接入源码；用户随后确认按这套五姿态继续施工。该确认用于锁定动作和制作方向，不代替高分辨率、实际听感及设备验收。前置问题见[状态核查](still-state-diagnosis-2026-10-23.md)。

## 最终姿态

| ID | 状态 | 姿势与使用方式 |
| --- | --- | --- |
| work | 伏案工作 | 向电脑前倾，双手落在键盘上；日常主姿态，75–120秒 |
| cup | 捧杯休息 | 靠坐、双手低位捧杯，杯子离开嘴边；45–70秒 |
| thinking | 托腮思考 | 手肘有支撑，一手托腮，另一手自然放下；40–65秒 |
| window | 侧身看雨 | 侧脸看窗外，双手放在腿部/扶手，区别于托腮；45–70秒 |

不增加第六个动作。阅读、闭眼和单独微笑退出当前选项；已保存的旧姿态回到自动模式，语音、音量、草稿和项目数据保留。

## 生成与实际清晰度

使用内置 image_gen 参考图编辑。先以原女生 work 为参考生成新工作母版，将电脑移到固定小桌，再让其余四张全部引用这一张母版。保留黑色双马尾、红衬衫及雨夜房间。每张完整制作，手臂、肩背、头颈均参与变化。首次看雨候选形成托腮姿势，将其归入 thinking，另生成双手放下的 window。

五张原始生成图位于 [female-v2](../../prototypes/live2d-codex/assets/stills/female-v2/work.png) 同目录；当前主应用使用 [female-v2-4k](../../prototypes/live2d-codex/assets/stills/female-v2-4k/work.png) 同目录的五张3840×2400成品。完整提示词见 [prompts-v2.json](../../prototypes/live2d-codex/assets/stills/prompts-v2.json)，尺寸、字节数和SHA-256见[清单](../../prototypes/live2d-codex/assets/stills/manifest.json)。

内置生成工具请求目标3840×2400，但五张实际输出均为 **1586×992**。后续高清加工得到 **3840×2400超分4K**，与先前两张原女生壁纸采用的流程一致；不是原生4K绘画。运行时按显示器分辨率绘制，截图尺寸本身不能证明素材清晰度。场景共享镜头与生成参考，没有用程序只拼头部来隐藏姿态差异；局部细节和切换观感仍需用户验收。原女生六张和男生两张均保留，男生沿用既有绘制方式与默认声线。

用户确认后，用已确认的 work 图做了一次仅提升清晰度、锁定人物与构图的内置工具编辑试验。请求3840×2400，实际仍返回1586×992，并重绘部分雨滴与纹理，因此不采用该候选，也不重复生成其余四张。提示词与实际结果记入 prompts-v2.json；原五张文件和哈希保持不变。

用户提醒核对旧流程后，确认2026-10-16已经采用过本地静态超分并通过当时验收。旧制作参数仍在，原工具目录已不存在，也未在项目归档与常见位置发现下载包，因此从[官方v0.2.5.0](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0)恢复同版45,474,481字节便携包，SHA-256与历史记录一致。加工过程为：`realesrgan-x4plus`、4倍、tile 192；Lanczos缩至3837×2400，左右延展1/2像素补至3840×2400以避免裁剪；65%超分与35%原图等尺寸放大混合。未启用人脸修复、重绘或调色。

先检查工作图的整体、脸、手、雨窗，再处理并检查其余四张脸和手。五张缩回源尺寸后的SSIM为0.983619–0.984489，只作为整体变化的辅助指标，不代替身份和细节验收。工具、原图/成品哈希与参数见[加工清单](../../prototypes/live2d-codex/assets/stills/processing-v2-4k.json)。复现入口为 `npm run art:stills-4k -- --run --poses=work --id=<新的目录名>`；默认只显示帮助，不自动下载、不覆盖旧输出或主应用素材。工具只在制作时运行，正常壁纸播放不需要超分模型。

## 主应用行为

女生完整目标帧解码后一次切换，不插入过渡图、不叠化。图片失败、过时加载、持久化失败和暂停期间仍保留原画面；既有重试和人物声线提交保持。

每轮随机排列捧杯、托腮、看雨，各出现一次，中间回到工作；轮次边界避免紧接着重复同一种休息姿态。任务执行时工作，交互时陪伴。长期连接错误不再永久锁住人物；暂停、不可见和交互仍冻结闲置计时，结束后继续剩余时间。成功回复不再闪入额外微笑图。

工作台提供五张缩略图、固定姿态选择、当前画面及暂停/交互原因。点缩略图固定姿态，选择“自动”恢复编排。主进程只接受当前人物和请求对应的状态，日志记录实际姿态。

小雨与轻敲音源、音量不变，轻敲只在工作姿态启用；录音静音、朗读降音优先于手动姿态。对话框、工作台、男女切换、声线、播放和遥控路径保留。
