## 发布复核

- Claude SDK 的当前 `ApiKeySource` 类型包含历史 `oauth` 值，不能把任意非空来源当作 API。现只接受三个已知 API 来源，或 SDK 返回的七类已知云 API provider；纯 OAuth、空值、未知来源拒绝连接，原会话/草稿保留。CLI 查询阶段不发送提示词；不自动创建或切换计费凭据。界面使用 Claude 名称，指南与[官方 SDK 认证/命名要求](https://code.claude.com/docs/en/agent-sdk/overview)一致。
- 正式打包原先只保护 staging，可能在 staging 不存在时覆盖已有安装器输出。现在正式/测试/便携入口共享版本一致性与新目录检查，已有产物和半成品一律保留；有独立文件系统回归。
- 安装包中的 CLI 指南原先指向安装目录之外的开发文档。正式包改成该版本的仓库链接，Test 包保留本地验收文件链接。
- 更新实际设置分类、电脑听写/朗读/停止名称、遥控清空/撤销/发送/音量说明，以及源码与安装版的启动区别。隐私说明准确区分未保存原始音频与本地脱敏遥控诊断。
- 根目录和应用的 npm 官方审计均为 0 项已知漏洞；这是本次锁文件检查结果，不是所有原生组件的安全保证。保留 SDK、Koffi 和原 CPU 语音组件许可；模型、Agent CLI、凭据不进入基础包。
- 新增维护入口 `npm run qa:release-package` 校验包版本、逐文件哈希、随包源码、未登记文件与分发边界；人物恢复 QA 已适配新分类导航。运行输出统一在忽略的 `work/qa`，不新增根目录过程文件。隐藏窗口截图初次遇到 UnknownVizError 后，验证工具改为主动请求帧、保持隐藏表面唤醒并仅对该瞬时错误限次重试，全部布局/交互断言随后通过；人物 QA 等待持久化完成再断言，避免把异步保存误判为失败。
