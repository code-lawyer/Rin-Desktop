# 静态壁纸接入主应用

2026-10-22，ART-09。女生六种姿态、小雨和轻敲键盘已接入主应用，使用原有对话、工作台、语音与遥控入口。用户已取消视频和过渡图路线；本轮没有发布安装包。

## 画面与操作

工作台 → 壁纸与设置 → 壁纸，可以选择自动模式或专注工作、阅读屏幕、望向窗外、闭目休息、看向用户、轻微微笑。选择自动保存。男生仍提供工作和回应，遥控器会跳过不适用的选项。

壁纸从 `wallpaper-renderer.js` 进入 `still-wallpaper.js`，直接绘制静态画布，不再通过壁纸网格变形、手部摆动或透明度过渡模拟人物动作。图片解码完成后一次替换，未解码或失败保持当前画面；快速请求采用最新目标，暂停后保留最后选择。失败的图片请求在重试时使用新请求地址，避免浏览器缓存失败响应。工作台保留明确的重试按钮。

六姿态共用原女生 3840 × 2400 工作场景，只有头部区域变化，窗景、家具、躯干和手部保持稳定。原工作与注视素材均为 3840 × 2400；新增四图由内置 image_gen 编辑，实际为 **1586 × 992**。静态区域接合消除背景闪动，但新增头部不是原生 4K 细节，不能把画布尺寸当成美术已通过验收。素材、实际尺寸、哈希和完整提示词见[资源说明](../../prototypes/live2d-codex/assets/stills/README.md)、[清单](../../prototypes/live2d-codex/assets/stills/manifest.json)和[提示词](../../prototypes/live2d-codex/assets/stills/prompts.json)。

自动模式以工作为主，每次停留约 75–120 秒，再随机选择阅读 24–40 秒、望窗 20–35 秒或休息 8–14 秒，之后回到工作，不连续重复上一种休息姿态。对话、听写、朗读、审批与错误触发关注；Agent 运行时回到工作。仅成功完成回复的事件触发约 3 秒微笑，随后恢复当前状态；错误与审批优先。手动选择用于立即查看某张姿态，不改变声音安全规则。

人物选择由主进程在图片解码后通过 `WorkspaceStore.prepareSettings()` 准备文件，再由可信壁纸窗口确认显示时完成最终替换与绘制。普通设置与人物准备共用 `applySettings()` 校验和默认声线入口；加载、准备或替换失败保留原人物和声线。暂停或更新目标可撤销准备，姿态改变不会重设声线。此为全项目审查后的修正，详见[五项修复与复审](five-fixes-review-2026-10-22.md)。

## 环境音与语音边界

工作台壁纸页下方的「窗边环境音」默认关闭，小雨默认 12%、轻敲默认 8%，独立保存，与朗读音量无关。音源延用经处理的 CC0 实录，见[音源说明](../../prototypes/live2d-codex/assets/ambience/README.md)。雨声循环，键盘用自然短句与停顿，仅在实际显示工作姿态且没有朗读或听写时播放。

只有壁纸窗口创建环境音播放器。主进程下发音频状态版本，壁纸应用静音/停止键盘后回执；电脑 `getUserMedia` 与 RC003 开麦指令均等待这份确认。确认超时拒绝开麦并允许重试，不在声音仍播放时继续。确认 renderer 已退出后允许语音降级使用，重试会恢复壁纸及回执要求。电脑取消、识别结束、遥控器结束与异常按所属采集会话释放静音状态，避免旧请求清理新录音；朗读等待也按播放版本处理迟到结果。

朗读界面在真正播放 PCM 之前通知主进程并等待降音确认，播放结束、停止或错误后释放；准备语音本身不触发降音。朗读时雨声压至用户设置的 20%，键盘停止。手动暂停、桌面遮挡、窗口隐藏、锁屏与休眠会静音并暂停闲置计时；唤醒后按当时状态恢复。声音加载失败可通过「重试加载环境音」单独重试。工作台和对话不各自叠加播放环境音。
