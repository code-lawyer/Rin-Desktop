## 限制与遗留

说明未覆盖环境、失败是否阻断本次范围、关联任务及下一动作。不要把旧结果或合成测试写成当前实机通过。

## 更新台账

只有退出条件满足才更新为 verified，给 evidence.ref 添加公共测试或脱敏报告路径和范围说明，运行 `npm run project:docs` 与 `npm run check:project`。
