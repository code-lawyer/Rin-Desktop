# 2026-10-22 前端视觉终验

本轮检查当前源码中的静态人物、对话气泡、工作台及遥控焦点。保留雨夜人物、浅蓝半透明气泡和青灰工作台的既有风格。完成一次集中检查、一批修正和一次视觉确认；没有重新生成美术或改变人物路线。

结论：本轮覆盖的前端布局与离线交互通过；原生 4K 新姿态美术和真实设备验收尚未完成。UI-03 保持已实现，ART-09 保持施工中，UI-02 的系统显示环境验收保持待施工。

## 发现与修正

| 发现 | 修正和确认 |
| --- | --- |
| 高度受限时，气泡固定区总高度超过卡片，底部听写、发送被 `overflow:hidden` 裁掉；审批正文被挤成不足一行 | 卡片在必要时纵向滚动，回复区保留 64px；审批标题、按钮不收缩，正文独立限高滚动。最小窗口、紧凑审批和问题表单均验证滚动后控件可达。正常大小继续使用回复区滚动。 |
| 环境音滑杆沿用了棕色，与工作台其余音量/操作控件不一致 | 改用既有 `--accent` 青灰色；没有改变声音、音量和保存逻辑。 |

修改位于 [气泡样式](../../prototypes/live2d-codex/renderer/style.css)、[工作台样式](../../prototypes/live2d-codex/renderer/workbench.css)。没有改动 Agent、语音或遥控器业务逻辑。

280×190 是气泡的极限尺寸压力用例；真实主程序通常根据内容自动增高，工作区不足时才会受限。通过意味着可滚动操作，不意味着这么小的窗口能同时完整显示全部内容。长审批的正文也仍需滚动。
