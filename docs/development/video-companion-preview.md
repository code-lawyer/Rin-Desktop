# 独立视频人物样例

> 路线变更（2026-10-22）：用户已明确放弃视频片段方案，当前方向为 [4K 静态壁纸与环境音](static-wallpaper-plan.md)。下文是此前研究/试用的历史记录，后续视频制作与验收计划已停止；已有代码和素材保留，主应用视频入口已由 ART-09 退出，当前实现见[原画恢复与第一阶段小样](static-wallpaper-preview.md)。

本轮对应 ART-05：先用本地参考视频验证独立播放器，再定制自己的角色视频。现有男女壁纸、声线设置与主应用入口保持原状。样例是预制视频播放，不是 Live2D，也不包含任意语音的实时口型。

## 启动

先按[构建说明](../build.md)准备项目的 Node、Electron 与 esbuild 依赖，再执行：

```powershell
npm run video:import -- --source="<本地参考素材目录>"
npm run start:video
```

`start:video` 构建并打开本项目自己的 Electron 窗口。也可运行 `npm run preview:video`，在浏览器打开终端给出的本机地址；默认端口 5319。只构建使用 `npm run build:video`。

导入器只复制三个 1080p WebM 和对应 JPG，不复制或执行参考项目的 HTML、JavaScript、插件或宿主接口。复制结果与独立素材清单位于忽略的 `work/runtime/video-companion/media`；播放过程仅访问该副本。第一次导入后，启动与播放均不读取外部安装目录，也不需要 Steam 或 Wallpaper Engine。参考素材仅用于本机验证，不进入公共源码或安装包。

## 已实现的逻辑

- 清单定义每段视频的入场与循环区间；默认直接进入循环，可单独重放入场。三段分别占位“陪伴、专注、等待回应”，名称用于检验状态选择，不表示参考片中的动作已经符合未来产品语义。
- 两个原生 HTML video 轮换：备用通道提前解码到循环起点；新通道收到帧回调后才替换当前画面。按帧时间触发接缝，避免每次从入场重播。
- 快速切换取消旧请求；过期加载、帧回调与循环交接不得覆盖新目标。当前画面始终保留到新视频就绪。
- 暂停和窗口隐藏分别管理。手动暂停在隐藏/恢复与状态选择之后仍有效；播放静音，不接管系统声音。
- 读取、解码或交接失败时暂停并保留当前视频帧，显示明确的“重试加载”按钮；重试保留用户最后选择的素材目标。
- 素材服务仅监听回环地址，支持 Range / 206、HEAD 和无效区间 416。文件路径采用素材白名单；页面的资源策略只允许本机同源资源。

播放控制器位于 [player.mjs](../../prototypes/video-companion/player.mjs)，HTML 视频适配位于 [video-deck.mjs](../../prototypes/video-companion/video-deck.mjs)，素材约束位于 [catalog.mjs](../../prototypes/video-companion/catalog.mjs)。独立窗口入口见 [desktop.cjs](../../prototypes/video-companion/desktop.cjs)，媒体服务见 [video-preview-server.mjs](../../tools/project/video-preview-server.mjs)。

## 验证与边界

`npm run test:video` 使用合成媒体接口、临时素材与回环服务器，检查循环交接、失败重试、取消竞态、暂停/隐藏、资源释放、清单、媒体区间和仅导入媒体的边界。不读取实际参考视频，也不调用账户或设备。

浏览器内展开“运行验证”，点击“运行播放验证”才执行真实素材检查。维护用例为 [video-companion-browser.mjs](../../tools/qa/video-companion-browser.mjs)：连续十次自然循环，随后检查暂停/恢复、另两段接缝、故障保帧、重试、快速切换及暂停时重放入场。验证期间保持页面可见；完成结果显示在页面，逐次证据保存到忽略的 `work/qa/video-companion`。

2026-10-22 验证记录：

- 离线专项 10 项通过；项目回归 256 + 72 项通过；主应用与样例构建通过。
- 实际浏览器验证 138 秒，15 项检查全部通过，含十轮自然循环和另两段接缝。1349 次画面状态采样中没有出现当前可见通道未解码的情况，交接等待最长 51 ms；此时间是等待新帧的耗时，不是黑屏时长。
- 手动点击“模拟读取失败”，页面显示保留画面与重试入口；点击“重试加载”后恢复到所选素材。保存了失败保帧与恢复后截图。
- `start:video` 已实际启动独立 Electron 窗口并完成本机页面加载。可见画面与交互由浏览器检查；未将窗口启动日志当作完整桌面/安装验收。
- 项目台账、公共链接和工作树公开边界检查通过。仅有媒体副本与运行证据写入忽略目录，没有引入参考壁纸脚本或宿主依赖。

画面状态采样证明解码与交接状态，不足以证明每一帧的视觉无缝或长期 GPU 性能。当前状态间直接切换；后续自制片应统一镜头、姿态、服装及端点，必要时增加专门过渡片。真实 Agent 状态绑定、语音口型、桌面嵌入、多显示器与正式安装包不在此样例的验收范围。
