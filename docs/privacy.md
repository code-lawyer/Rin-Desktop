# 隐私与本机数据

应用自身不上传录音、语音缓存、桌面截图或壁纸。听写与播报在本机完成，麦克风只在明确开始听写后打开。完成语音仅缓存在内存中，退出后释放。

发送给 Codex 的文字、代码与工具请求由官方 CLI 按你的账户及权限访问 OpenAI 服务。本地语音不代表 Codex 离线运行。应用不代替你批准命令、文件修改或权限请求。

官方 CLI 管理登录凭据及规范会话历史。应用状态默认保存于 `%LOCALAPPDATA%\VibeVoice`，沿用旧项目名称以兼容升级；这里包含项目入口、草稿、声音和按键设置、窗口位置。安装目录与数据目录分离，卸载不删除上述数据，也不删除 `.codex`。

从早期便携版升级，可在工作台「语音与按键」选择「使用已有数据目录」。选择含 `workspaces.json` 的旧目录，应用重启后直接沿用它，不覆盖已有文件。请保留这个目录；跨电脑迁移还需要在新电脑重新登录，并重新定位不再存在的项目路径。

语音资源只在你点击下载后从本仓库固定 Release 获取，逐文件校验 SHA-256；下载请求不携带对话或录音。资源存于数据目录的 `voice-resources`，卸载应用会保留，方便重新安装复用。取消下载保留可续传的部分文件，安装成功后清理下载缓存。Qwen 缺少 VC++ 运行库时另访问微软官方下载地址。

公开源码及 Release 不包含维护者的账号凭据、API Key、私有隧道、会话历史、录音、个人截图、麦克风标识或本机配置。
