# 隐私与本机数据

应用自身不上传录音、语音缓存、桌面截图或壁纸。听写与播报在本机完成，麦克风只在明确开始听写后打开。完成语音仅缓存在内存中，退出后释放。

0.5.0 的 RC003 接入在你连接遥控器后接收按钮事件，按住语音键时请求麦克风音频，松开后在本机识别并写入草稿。设备名称、本机连接标识、自动连接与按钮设置保存在 `workspaces.json` 的 `settings.rc003`；不默认保存原始音频。应用向本地标准输出写入脱敏诊断，包括已确认的遥控按钮名称、对应功能、采集阶段、帧数与时长；源码后台启动器会把这些输出保存在 `work/runtime/launcher`，自行重定向输出也会留下日志。这些诊断不记录普通键盘文本、识别正文或原始设备路径。清除应用连接记录不会解除 Windows 配对；不启用自动连接时，应用重启后需手动连接。设备来源判断仅用于应用交互，不采集其他程序中输入的文本。

发送给当前 Agent 的文字、代码与工具请求由其原生 CLI 按你的账户、模型提供商和权限配置访问相应服务。Codex 使用 OpenAI；Claude Code、Grok Build、OpenCode 使用各自配置的服务。本地语音不代表 Agent 离线运行。应用将收到的审批请求交给你处理；CLI 原生配置已允许的操作可能不会发出审批，尤其是 OpenCode 的项目、全局和 Agent 权限规则。

原生 CLI 管理登录凭据及完整会话历史。应用不读取、复制 CLI 凭据文件，不向页面传输密钥；启动环境中的认证变量由对应 CLI 使用。Claude 实验入口仅使用 API 或官方云平台 API 认证，费用由你配置的提供商计收，不使用 Claude 订阅额度，也不自动更换凭据。应用状态默认保存于 `%LOCALAPPDATA%\VibeVoice`，沿用旧项目名称以兼容升级；这里包含项目入口、草稿、声音和按键设置、窗口位置。新增 Agent 的 `agents/<名称>` 子目录另保存会话编号、项目路径、显示名称和最近 200 条消息缓存。安装目录与数据目录分离，卸载不删除上述数据，也不删除各 CLI 的账户和会话目录。

从早期便携版升级，可在工作台「壁纸与设置 → 数据」选择「使用已有数据目录」。选择含 `workspaces.json` 的旧目录，应用重启后直接沿用它，不覆盖已有文件。请保留这个目录；跨电脑迁移还需要在新电脑重新登录，并重新定位不再存在的项目路径。

应用还在 `workspaces.json` 中为每个 Agent 保留最近一次发送原稿、目标和确认状态，用于断线/重启后的核查；核查只读取原生历史，不自动重发。下一次有意发送替换这条记录。JSON 的 `.bak` 和未提交 `.tmp` 可能包含旧草稿、消息缓存或设备设置，和主数据一样属于私人文件。恢复工具只向新目录复制，不上传这些内容。内部测试包默认使用 `VibeVoice/test-builds/<测试标识>`，与正式数据隔离。

语音模型只在你点击下载后从 Hugging Face 的固定 revision 获取，逐文件校验 SHA-256；下载请求不携带对话或录音。Qwen 的独立 Python 与环境工具来自 Astral，依赖来自 PyPI / PyTorch 索引，版本和哈希由应用锁定。资源存于数据目录的 `voice-resources`，卸载应用会保留，方便重新安装复用。取消下载保留可续传的部分文件，安装成功后清理下载缓存。Qwen 缺少 VC++ 运行库时另访问微软官方下载地址。

公开源码及 Release 不包含维护者的账号凭据、API Key、私有隧道、会话历史、录音、个人截图、麦克风标识或本机配置。
