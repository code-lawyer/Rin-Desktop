# 0.3.1 发布审查与验证

审查覆盖公开源码、Windows x64 安装候选和按需语音资源流程。此次修订以 `8fffc156` 为固定基线，分别进行 Standards 与 Spec 审查；自有代码使用 MIT，第三方组件保留其许可。

## 分发边界

- 基础包不包含 Codex CLI、任何语音模型、Qwen Python 环境或模型下载缓存。CLI 由用户自行安装和登录。
- 模型只在用户点击管理面板的「下载并载入模型」后，直接从 Hugging Face 上游下载。本项目的仓库和 Release 不重新分发模型。
- Qwen 的独立 Python 来自 Astral，依赖来自 PyPI / PyTorch 官方索引。版本和哈希锁定；不修改系统 Python 或 PATH。缺失的 VC++ 运行库来自微软官方。
- 公开源码不包含账户、CLI 凭据、密钥、会话、录音、研究资料、开发环境或个人运行状态。
- CPU 语音组合组件的 GPL 条件与对应源码单独提供。公开安装版固定使用原有 4K 雨夜场景，不分发旧 Hiyori 角色。

## 本次检查

- 自动测试覆盖固定上游 URL、路径限制、下载校验、取消续传、Range 回退、缓存复用、磁盘检查、并发失败排空、子进程超时和模型载入互斥。
- 保存设置或加载模型期间退出的回归使用真实应用回调与可控的内存 worker，确认不会在退出后重新创建语音进程。
- 修复下载期间无法保存无关麦克风、快捷键及遥控器设置的问题；只有实际更改语音引擎等选项时才会阻止。
- 上游依赖安装保留显式代理设置；从资源管理器启动且无代理环境变量时，沿用桌面解析到的系统代理。HTTP 80 / HTTPS 443 默认端口已覆盖。
- 修复 CLI 连接尚未完成时退出可能触发同步错误弹窗、阻塞退出的问题。

## 运行验证

- 本地 132 项自动测试通过，其中 127 项属于公开源码，另 5 项为未公开的旧 Dots 测试。
- SenseVoice 与 Kokoro 的真实 Hugging Face 下载、逐文件校验和独立目录载入通过；中文合成后再转写，得到预期文字。
- Qwen 使用独立新装 Python 与固定依赖完成载入和中文合成，生成 4.08 秒音频。本次复用本机已有的 12 个模型文件，逐项验证与上游锁定哈希一致；没有重复下载 4.52 GB 权重。Python 与依赖的首次安装流程实际联网运行。
- 原生管理面板验证下载百分比和进度条、取消、续传、自动载入、释放后再次载入不请求网络。界面测试使用真实模型的本机流式传输以稳定复现进度；上游网络传输由上一项独立验证。
- 新安装候选通过 300 个文件的逐项校验，安装大小约 544 MB；再次完成官方 CLI 登录发起与取消、真实任务与追问、重启恢复会话及草稿。语音面板重启后保留已下载文件。
- 既有隔离卸载验收确认个人数据保留。本次原有个人状态文件与安装验证前逐项哈希一致。
- 原场景两张 4096×4096 图集及其模型文件保持逐文件 SHA-256 一致，场景内容为 3840×2400。模型下载与安装不写入原有个人会话和设置目录。
- npm 生产依赖审计在检查时未报告已知漏洞；这不等于对全部原生库作安全保证。发布资产附 SHA-256，CPU 语音对应源码附件已通过归档完整性检查。

运行验收在维护者的 Windows x64 机器和隔离目录中完成，没有覆盖全新 Windows 虚拟机或所有显卡、驱动和代理配置。Qwen 首次环境准备阶段显示活动进度条，不伪造安装百分比。安装器暂未代码签名。
