# 0.3.0 发布审查与验证

本次审查覆盖整个公开项目及 Windows x64 安装包；仓库此前没有提交历史，采用文件清单与运行验收作为范围。自有代码使用 MIT，第三方组件按各自许可分发。

## Standards

- 公开源码只包含应用、测试、构建工具和文档。个人账户、CLI 登录、隧道密钥、会话、草稿、录音、截图、下载缓存、开发虚拟环境和研究过程不进入 Git。
- 原生组件许可证、GPL/LGPL 对应源码与构建说明随 Release 提供。CPU 语音组合组件的 GPL 条件单独列明；4K 场景与专有 Core 的条款保留。
- 安装候选从新目录生成，禁止合并旧包。各发行资产有 SHA-256；自动下载入口与源码资源引导均校验锁定哈希。
- npm 官方审计：生产 Node 依赖 0 项已知漏洞（查询当时）。这不等同对全部原生库提供安全保证。

## Spec

- 基础包不含 Codex CLI 与语音模型。CLI 由用户自行安装、登录；应用发现 PATH、官方安装位置或标准 npm 安装的原生二进制。Node 与显示所需组件随基础应用提供。
- SenseVoice、Kokoro、Qwen 分别按需下载，文件大小、地址与 SHA-256 锁定。支持取消、续传、校验后安装、失败重试、磁盘空间检查；使用已有资源不重复下载。
- 首次登录使用官方 CLI 的 ChatGPT 浏览器登录接口；取消与迟到响应经过回归，旧请求不会覆盖新登录。
- Qwen 为可选组件，默认不驻留、不自动朗读。安装检查 VC++ 运行库；缺少时从微软官方固定地址下载并校验，可能需要管理员确认。
- 工作台支持沿用已有数据目录；选择期间暂停输入动作，避免切换目录丢失进行中的任务。应用数据位于安装目录外。
- 公共安装版固定使用现有 4K 雨夜壁纸，不分发旧 Hiyori 角色。场景文件与原版逐文件 SHA-256 一致：两张 4096×4096 图集，3840×2400 场景内容。

## 已完成验证

- 120 项公开代码 Node 自动测试及干净源码构建通过，包含 12 项按需资源回归：缓存重试、取消、Range 回退、路径限制、校验失败不执行、空间不足、安装超时与外部 CLI 发现。另有 5 项私人旧 Dots 测试只在开发目录保留。
- 隔离原生界面：全新 `CODEX_HOME` 显示登录入口，官方 CLI 发起/取消登录；使用本机已登录账户实际发送任务、继续追问，重启后恢复会话和草稿。
- 独立资源目录：Qwen 中文生成成功；精简 libsndfile 重编后 WAV 读写与 Qwen 生成再次通过。一次短句测试约 12.7 秒加载、9.1 秒生成 4.64 秒音频，属于本机单次验证，并非性能承诺。
- CPU Kokoro 合成 → SenseVoice 本地转写闭环通过，正确识别测试中文。
- 精简安装包约 259 MB、解包约 544 MB；隔离安装成功，确认不含 CLI 或语音模型。安装后的原生界面实际完成官方 CLI 登录发起/取消、任务发送、继续对话、重启恢复和资源设置页面检查。
- 三个真实语音包经本机回环 HTTP 流式传输、哈希校验、独立安装后可用，重复启用未再次请求网络。下载后的 Kokoro → SenseVoice 流程和 Qwen 合成都通过；此处验证传输与资源完整性，GitHub 远端下载另在发布后检查。
- 公开源码的资源引导脚本通过基础包校验和无注册安装项解包，可连接资源目录；原有 4K 文件哈希保持一致。
- 安装后 297 个文件逐项通过清单 SHA-256。卸载验收移除应用但保留外部会话数据；原开发实例的个人状态文件与测试前逐项哈希一致。
- 公开文件扫描未检出凭据、个人路径或运行状态；安装资源中的文本配置也检查了维护者路径泄露。

测试边界：原生运行验收在维护者的 Windows x64 机器上使用隔离目录完成，不代表已覆盖所有硬件、显卡驱动或全新 Windows 虚拟机。不同电脑仍需实际安装验证。安装器尚无付费代码签名证书。
