# 0.5.0 发布范围与验证

日期：2026-10-22。基于原 0.4.0 提交整合当前公共源码和开发文档；两轴审查的具体缺陷、修复与回归见[0.5.0 全项目审查](development/release-0.5.0-review.md)。原 GitHub 仓库、已有个人数据、模型与旧安装包保持。

## 分发范围

- Windows x64 单屏壁纸、原两个人物、Codex、本地听写/朗读、项目与会话工作台继续提供。设置分六类，朗读与实际播放音量有固定入口。
- RC003 连接、按钮配置、遥控麦克风、草稿清空/撤销/发送和媒体音量接线随本版提供；完整硬件矩阵仍属实验范围。用户“效果基本 ok”是有限反馈，未作为物理音量或休眠/IME稳定性通过。
- Claude、Grok Build、OpenCode V2 在界面和包清单保持实验标识。离线契约通过不代表真实账户验收。Claude 遵循 SDK 官方要求，仅接受用户配置的API/官方云API认证，不提供订阅登录或额度，也不自动切换计费来源。
- 基础安装器不含模型、Agent CLI、Qwen Python环境、个人会话、凭据或制作母图。模型继续按需从上游下载，已有模型可复用。

# 0.4.0 发布审查与验证

以 `cb75075e85e5c91945a9e958c2447f8785759bf7` 为代码基线，按 Standards 与 Spec 两个维度独立复审人物选择及其修复。两轴均无待处理发现。修复前的打包快照用于核对声线重复赋值和失败恢复行为。

## 修复结论

- 声线控件统一由 `fillVoices()` 填充，移除固定 Serena 的重复赋值。
- 新人物渲染成功后才保存人物及对应默认声线。模型或贴图加载失败保留原人物、自选声线与已保存设置，显示明确的重试按钮。
- 请求编号与已确认编号分开推进；延迟成功确认跟随实际显示的人物，不清除后续选择的错误和重试目标。过期失败不覆盖当前选择。

## 发布验证

- 136 项公开源码测试通过（桌面应用 118 项、根目录 18 项），前端构建通过。本机完整测试集另含 5 项不发布的旧 Dots 开发测试，也已通过。
- 源码与正式安装包安装后的 Electron 实例均完成模型失败、贴图失败、连续重试、键盘重试、快速取消切换、延迟确认、未保存表单保留与重启恢复检查，未捕获页面运行错误。
- 正式安装包以便携测试模式安装到独立目录，309 个发布文件逐项匹配 SHA-256 清单。没有注册或覆盖现有安装。本次未改动安装与卸载规则，0.3.1 的隔离卸载保留数据验收记录见下文。
- 33 个原女性场景与 CPU 语音组件文件相对 0.3.1 保持 SHA-256 一致，包括独立语音 worker 和 native 组件；继续提供原有第三方对应源码页。
- 默认女生保留原 4K 场景；新男生原画为 1586×992。两个人物的预览和运行资源均包含在安装包中。
- 基础包不包含 Codex CLI、语音模型或 Qwen Python 环境；模型仍由用户按需从上游下载。资源版本维持 1.0.0，升级不触发重新下载模型。
- 安装包校验值保存在 `tools/release/resource-manifest.json`，应用 Release 仅上传 `Rin-Desktop-0.4.0-Setup.exe`。安装器仍未代码签名。

验收在维护者的 Windows x64 机器与隔离目录中完成，没有覆盖全新 Windows 虚拟机或全部显卡、驱动与代理配置。

# 0.3.1 发布审查与验证（历史记录）

审查覆盖公开源码、Windows x64 安装候选和按需语音资源流程。此次修订以 `8fffc156` 为固定基线，分别进行 Standards 与 Spec 审查；自有代码使用 MIT，第三方组件保留其许可。

## 分发边界

- 基础包不包含 Codex CLI、任何语音模型、Qwen Python 环境或模型下载缓存。CLI 由用户自行安装和登录。
- 模型只在用户点击管理面板的「下载并载入模型」后，直接从 Hugging Face 上游下载。本项目的仓库和 Release 不重新分发模型。
- Qwen 的独立 Python 来自 Astral，依赖来自 PyPI / PyTorch 官方索引。版本和哈希锁定；不修改系统 Python 或 PATH。缺失的 VC++ 运行库来自微软官方。
- 公开源码不包含账户、CLI 凭据、密钥、会话、录音、研究资料、开发环境或个人运行状态。
- CPU 语音组合组件的 GPL 条件与对应源码单独提供。公开安装版固定使用原有 4K 雨夜场景，不分发旧 Hiyori 角色。

## 本次检查

- 自动测试覆盖固定上游 URL、路径限制、下载校验、取消续传、Range 回退、缓存复用、磁盘检查、并发失败排空、子进程超时和模型载入互斥。
- 保存设置或加载模型期间退出的回归使用真实应用回调与可控的内存 worker，确认不会在退出后重新创建语音进程。
- 修复下载期间无法保存无关麦克风、快捷键及遥控器设置的问题；只有实际更改语音引擎等选项时才会阻止。
- 上游依赖安装保留显式代理设置；从资源管理器启动且无代理环境变量时，沿用桌面解析到的系统代理。HTTP 80 / HTTPS 443 默认端口已覆盖。
- 修复 CLI 连接尚未完成时退出可能触发同步错误弹窗、阻塞退出的问题。

## 运行验证

- 本地 132 项自动测试通过，其中 127 项属于公开源码，另 5 项为未公开的旧 Dots 测试。
- SenseVoice 与 Kokoro 的真实 Hugging Face 下载、逐文件校验和独立目录载入通过；中文合成后再转写，得到预期文字。
- Qwen 使用独立新装 Python 与固定依赖完成载入和中文合成，生成 4.08 秒音频。本次复用本机已有的 12 个模型文件，逐项验证与上游锁定哈希一致；没有重复下载 4.52 GB 权重。Python 与依赖的首次安装流程实际联网运行。
- 原生管理面板验证下载百分比和进度条、取消、续传、自动载入、释放后再次载入不请求网络。界面测试使用真实模型的本机流式传输以稳定复现进度；上游网络传输由上一项独立验证。
- 新安装候选通过 300 个文件的逐项校验，安装大小约 544 MB；再次完成官方 CLI 登录发起与取消、真实任务与追问、重启恢复会话及草稿。语音面板重启后保留已下载文件。
- 既有隔离卸载验收确认个人数据保留。本次原有个人状态文件与安装验证前逐项哈希一致。
- 原场景两张 4096×4096 图集及其模型文件保持逐文件 SHA-256 一致，场景内容为 3840×2400。模型下载与安装不写入原有个人会话和设置目录。
- npm 生产依赖审计在检查时未报告已知漏洞；这不等于对全部原生库作安全保证。安装包 SHA-256 保存在仓库的资源清单中，GitHub 同时显示附件校验值。CPU 语音对应源码已通过归档完整性检查，单独保存在开发者源码页，由 README 和应用发布说明提供获取入口。

运行验收在维护者的 Windows x64 机器和隔离目录中完成，没有覆盖全新 Windows 虚拟机或所有显卡、驱动和代理配置。Qwen 首次环境准备阶段显示活动进度条，不伪造安装百分比。安装器暂未代码签名。
